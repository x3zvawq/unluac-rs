在浏览器与自己的工具中使用 Lua 反编译器

unluac-rs 是一个用 Rust 编写的免费开源 Lua 字节码反编译器，从编译后的 chunk 中恢复可读源码，支持 Lua 5.1、5.2、5.3、5.4、5.5、LuaJIT 2.1 与 Luau。

在线工作区可以查看字节码、编辑恢复出的源码，并探索函数、常量与控制流图。你也可以通过 CLI 离线反编译，或将 Rust 与 JavaScript 库接入自己的工具。

选择适合你的使用方式

在线工作区

在当前页面打开编译后的文件或文件夹。WebAssembly 引擎在你的设备上处理文件，无需上传服务器；每个文件独立保存 Lua 方言。

命令行反编译器

下载 Windows、macOS 或 Linux 的 CLI 二进制，在本地离线反编译。

unluac-cli -i sample.luac -o recovered.lua

JavaScript / TypeScript

在 Node.js 或使用打包器的浏览器应用中使用 unluac-js。

npm install unluac-js

Rust 库

将 unluac 加入项目，在 Rust API 文档中查看选项与流水线结果。

cargo add unluac

关于 Lua 反编译的常见问题

可以反编译哪些文件？

可以打开受支持 Lua 版本或方言编译出的字节码。文件可以使用 .luac、.out、.lua 或其他扩展名，识别依据是文件内容。普通源码文件也可以直接打开阅读和编辑。

文件会上传到服务器吗？

不会。反编译和结构分析通过 WebAssembly 在浏览器本地运行。浏览器保存原始字节与方言选择，供下次访问时恢复。手动编辑的内容请在离开或刷新页面前下载保存。

能恢复完全相同的原始源码吗？

反编译会重建程序结构，但无法找回编译时丢弃的注释等信息。已有调试信息可以帮助恢复命名。项目仍处于测试阶段，不支持的结构或缺陷可能影响输出；请检查生成代码，并反馈可复现的问题。

如何反馈反编译问题？

请提交 GitHub issue，附上可复现样本、Lua 版本、使用的选项，以及预期与实际行为。若有原始源码，也请一并提供。欢迎代码、文档和测试用例方面的贡献。
