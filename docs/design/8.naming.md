# AST Naming

> **职责**：把最终 AST 中的稳定 binding 身份映射成合法且无歧义的字符串名字，输出 `NameMap`。
>
> **不负责**：改变 AST、恢复结构、删除 binding 或发明前层缺失的身份。

## 入口与数据流

```text
src/ast/naming/mod.rs
  collect_naming_evidence(hir_module)
  assign_names_with_evidence(ast, hir, evidence, options)
  assign_names(state, context)

HIR capture facts      -> NamingEvidence
HIR debug hints        -> strategy
final AstModule         -> lexical/binding facts
                         -> strategy -> allocation -> NameMap
```

## 模块 owner

| 文件 | 职责 |
| --- | --- |
| `common.rs` | `NameMap`、evidence 与 naming options |
| `evidence/` | HIR capture provenance 的收集与一致性校验 |
| `ast_facts.rs` / `lexical.rs` | AST 词法作用域和可见性 |
| `strategy.rs` | 候选名来源与优先级 |
| `visibility.rs` | 按函数定义位置查询已分配名字的可见区间 |
| `allocate.rs` | 关键字、冲突、遮蔽与 suffix 分配 |
| `assign.rs` | 组装按函数分区的最终映射 |
| `validate.rs` | 目标方言标识符合法性 |

## 稳定合同

- Naming 只处理 readability 后仍存在的 Param/Local/Upvalue/SyntheticLocal；Temp 到达这里表示前层
  未收敛。
- 变参参数寄存器的可见性和命名证据来自 `HirProto::vararg_param_local`，不依赖 local 分配顺序。
- debug 证据影响可读性但不是正确性前提；无 debug 输入必须仍能稳定、确定地命名。
  候选名直接借用当前 HIR 的四类 debug 提示，不复制命名专用数组；NamingEvidence 只保存
  同一 HIR 的捕获来源，root/detached proto 的缺省行表示没有捕获证据。
  已物化 HirTemp 按原 TempId 查询 debug/capture 名字；AST 自建 local 只使用当前 AST hint
  和命名策略，不以同号 index 查询 HIR 数组。名字冲突按完整 typed identity 分配并消解。
- 已证明的 capture provenance 优先保持父 binding 身份，不能被子 proto 的提示名覆盖。
- 词法边界来自最终 AST；名字分配必须同时避让同作用域冲突、目标方言关键字和会被后代 capture
  遮蔽的裸全局。
- 裸全局名按最终 AST 的函数后序位置发布到共享 `PositionIndex`；每个函数保存其子树区间，
  所有候选名冲突查询都消费该区间。父函数避让后代名字，兄弟函数互不污染；不按 HIR.children
  重建最终子树，也不逐祖先复制全局集合。函数自身已分配的名字仍由本地 allocator 保存。
- 外层绑定可见性按最终 AST 的闭包定义前序位置记录：声明生效后到词法作用域退出形成半开区间。
  父函数完成命名后发布名字与区间，同名区间合并，子函数直接查询定义位置；不复制祖先绑定或名字集合。
  普通声明的初始化式先于绑定生效，local function 的绑定先于函数体，repeat 条件仍在 body 作用域中。
  分配仍按 HIR proto 顺序推进，区间索引不改变模块级后缀顺序。
- VM 固定名字或语法隐含名字属于语义约束，优先于普通命名策略。
- `NameMap` 按函数上下文组织，Generate 进入 child proto 时必须切换映射。
- 分配结果必须只由输入事实和选项决定，不能依赖 hash/遍历偶然顺序。

具体候选优先级、suffix 推进和方言关键字集合见 `strategy.rs`、`allocate.rs` 与 `validate.rs`，不在
本文逐规则复制。

## 排错

| 症状 | 首查位置 |
| --- | --- |
| 名字退化为通用序号 | `evidence/` 与 `strategy.rs` |
| closure upvalue 名错误 | `evidence/capture.rs` |
| 冲突、遮蔽或 suffix 异常 | `visibility.rs` | 按函数定义位置查询已分配名字的可见区间 |
| `allocate.rs` |
| 标识符不合法 | `validate.rs` 与目标 dialect |
| 查看 Naming 结果 | `unluac --debug --dump ast --stop-after ast <file>` |
