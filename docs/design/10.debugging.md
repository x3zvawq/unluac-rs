# 调试实现 Code Map

本文只说明调试能力的代码 owner。命令与排错流程见 `docs/debug.md`。

## 数据流

```text
CLI options
  -> DecompileOptions / DebugFilters
  -> stage scheduler
  -> layer debug renderer / pass snapshot
  -> stderr
```

正常反编译结果只写 stdout；debug 设施观察业务事实，不创建或修复业务事实。

## 核心 owner

| 位置 | 职责 |
| --- | --- |
| `src/decompile/options.rs` | 调试选项入口 |
| `src/decompile/stages.rs` | stage dump、timing 与 pass dump 调度 |
| `src/debug.rs` | 公共类型与 stage dump 宏 |
| `src/debug/focus.rs` | proto/depth 聚焦与稳定编号 |
| `src/debug/colorize.rs` | ANSI 展示 |
| `src/timing.rs` | 阶段与 pass timing |
| `src/hir/simplify/mod.rs` | HIR pass before/after snapshot |
| `src/ast/readability/mod.rs` | AST pass before/after snapshot |
| `src/structure/diagnostic.rs` | 无 debug feature 也可用的 proto 失败诊断 |

## Stage dump

| Stage | 入口 |
| --- | --- |
| Parser | `src/parser/debug/mod.rs::dump_parser` |
| Transformer | `src/transformer/debug.rs::dump_lir` |
| Structure | `src/structure/debug.rs::dump_structure` |
| HIR | `src/hir/debug.rs::dump_hir` |
| AST | `src/ast/debug.rs::dump_ast` |
| Generate | `src/generate/debug.rs::dump_generate` |

Structure dump 内含 CFG、GraphFacts、Dataflow 与 final plan；AST dump 内含 build、Readability 与
Naming。内部子步骤应扩展所属 stage 的分段，不新增公开 stage 名。

## 共享合同

- 所有 proto-aware dump 复用 `compute_focus_plan`，保持稳定 DFS 编号和 visible/elided/hidden 语义。
- Transformer 之后新增的 closure occurrence 以 lowered proto identity 编号，不伪装成 parser slot。
- Generate 不裁剪 proto，因为局部文本会失去语法完整性。
- `ProtoFailure` 的生产诊断必须在 no-default-features/WASM 中可用，因此不能调用 feature-gated
  debug renderer。
- pass dump 只在实际发生变化时输出，并复用 HIR/AST 的快照格式。

新增调试参数时，配置归 `decompile/options.rs`，调度归 `decompile/stages.rs` 或业务层入口，展示
归对应 `debug.rs`；业务模型不得依赖 debug feature。
