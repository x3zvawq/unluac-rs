# Generate

Generate 把稳定 AST 与 NameMap 渲染为目标方言文本。
它负责语法发射和布局，不恢复控制结构、不分配名字、不补做可读性改写。

## 入口与数据流

入口：[generate/mod.rs](../../src/generate/mod.rs) 的 `generate_chunk`。

```text
AstModule + NameMap + metadata + GenerateOptions
  -> emit -> Doc -> render -> GeneratedChunk { kind, source }
```

## 子处理层

| Owner（src/generate/） | 消费 | 生产与后继 |
| --- | --- | --- |
| [common.rs](../../src/generate/common.rs) | 输出请求 | GeneratedChunk、模式、布局与方言选项 |
| [emit/expr.rs](../../src/generate/emit/expr.rs) | AST 表达式 | 保留优先级和分组的 Doc |
| [emit/stmt.rs](../../src/generate/emit/stmt.rs) | AST 语句与块 | 语句边界、函数头与块 Doc |
| [emit/syntax.rs](../../src/generate/emit/syntax.rs) | 字面量与目标语法 | 字节转义、数字和 token 边界 |
| [emit/names.rs](../../src/generate/emit/names.rs) | binding 与函数上下文 | NameMap 中的最终名字 |
| [emit/luau_inlining.rs](../../src/generate/emit/luau_inlining.rs) | HIR 编译要求及最终 AST occurrence | 所需 Luau 编译合同的最终校验 |
| [doc.rs](../../src/generate/doc.rs) | emit 的布局树 | 与语义无关的布局 IR |
| [render.rs](../../src/generate/render.rs) | Doc 与行宽/缩进选项 | 最终字符串 |

## 稳定合同

- Generate 只输出 AST 已表达的语义，不猜 attribute、binding、value wrapper 或缺失节点。
- emit 决定语法和括号，Doc/render 决定布局。折行和紧凑模式不能改变分组、求值顺序或语句边界。
  Luau 复合全局更新只按 AST 携带的 HIR 证明发射；标记的形状或目标方言不符时报告错误，
  不静默改成具有不同寄存器准备的普通赋值。
- 操作数顺序由 AST 决定；输出层不为好看交换比较两侧或改变逻辑树。
- 数字和字符串必须可重编译为同一值。可执行字面量使用原始 bytes；
  Parser 的 GBK 等解码视图只能用于展示，不替换字节值。
  极端有限浮点数使用可往返的科学计数法，保留负零及有整数/浮点区分方言的浮点类型；
  相同格式也用于 HIR 已认证的数值 capture initializer。
- 函数名字从当前 NameMap 读取；进入 child 时切换函数上下文。
  `global function` 只按 AST 的显式声明来源发射，不从目标名字属于 global 推断声明。
- HIR 发布语义必需的 Luau 编译要求时，Generate 针对最终 AST 验证后才输出所需 pragma。
  该合同依赖 pinned 编译器，升级时须核对 `emit/luau_inlining.rs` 与相关测试；
  具体成本、阈值和封闭形状以实现为准。不能把编译要求当作可关闭的展示注释。
  编译要求区分构造结果和索引结果的函数体合同，不仅按访问的字段名匹配；带 debug 的
  内联参数还须有身份归属证明，普通 local 的保留约束不能由内联候选绕过。
  必须内联的调用以原展开帧内的代表操作标识，随 HIR/AST 调用节点传递；结果 local
  不是调用身份。最终校验须将每项要求与唯一调用对应，并核对 callee 及调用语境，
  不能因结果声明消失而遗漏编译要求，也不能将该身份当作原字节码 CALL 来源。
  调用可以位于比较或短路表达式内；校验沿表达式保留固定单值语境并计入额外暂存槽，
  每项 occurrence 仍须唯一匹配。开放尾调用不能借返回值个数推断省略这项编译约束。
  外围闭包与普通表操作可共存，但必须排除额外函数内联、builtin 折叠及开放尾部
  返回数量变化；进入 child 前核对必需 callee 未被捕获，并按 child 的身份域验证。
  捕获更新型函数体还须核对父级 cell 身份、完整写入和返回表达式；常量实参已被原编译器
  折叠时，只允许精确重发原常量操作的替代实参，不将它们报告为恢复出的原参数。
  标量 NOT 更新后的 CALL 同样可以发布必需内联合同；函数体须保留逐次赋值边界，
  调用点须保持 Boolean 实参。最终核对操作数量、函数体成本与寄存器上限，避免常量
  实参将整条更新链折叠掉，或在 VM 中留下原字节码不存在的 helper 调用。
  HIR 已认证的 `type` / `tostring` FASTCALL 函数体可沿同一合同发射；固定单返回的
  builtin 返回语境与普通全局 CALL 分开核对，不将 fallback 读取改成另一种调用协议。
  捕获更新的单值参数调用可以嵌入原方法调用或已重写 local 的普通调用；后者须排除
  Luau 再次解析并内联外围 callee。零参数工厂另核对共享闭包模板、完整构造体及递归
  捕获关系，避免重新生成的 child 在不同编译位置发生额外内联。所有合同继续受
  最终声明前缀、函数体成本和寄存器上限约束，不能只验证样例的运行输出。
  发布表工厂核对只读捕获容器、完整分配/字段写入/返回体；参数位置保持固定单值。
  固定双结果调用同时核对声明或赋值的原前缀、返回宽度和只读捕获；内部 callable 来源须
  保持不透明，不能在恢复外层调用时额外内联资源产生函数。外围函数也可由最终 AST 的
  分配成本下界证明不可内联，嵌套函数体独立验证，不把其成本计入父函数。
  原 debug 形参对应的匿名恒等表达式必须在闭包创建前内联，不能退化为运行时 IIFE；
  其参数名、固定单结果参数及空捕获由独立函数体合同核对。
  词法块内部继续逐项验证，离开时恢复外层声明前缀。外围 vararg 与高成本固定循环函数
  由 `emit/luau_inlining/opaque` 核对不可内联条件；捕获调用使用 HIR 的有序 capture 身份，
  不按上值编号或名称猜测 callee。最终 AST 函数体变化会使该编译证明失效。
  无捕获共享工厂的机械调用可按 reusable 模板合同消失；其返回值仍保持普通调用边界。
  外围数值循环须排除 O2 展开：最终 AST 重新核对循环变量的常量折扣与函数体成本下界，
  不能沿用 HIR 改写前的成本或只依据原输入中存在循环。
  条件方法模板另核对原函数身份、完整条件树的成本以及只读 local 实参，包含后续赋值和
  子闭包写入；该实参必须仍可复用原低槽。外围 generic-for 不参与数值循环展开，但其
  迭代器和函数体仍须排除额外 O2 改写；经 `pcall` 传递模板函数不等于直接调用模板。
- 开启注释时，每个实际输出的函数在 `function(...)` 参数表之后同行附加一次 proto 元信息。
  具名声明、匿名值、表字段、回调和 IIFE 共用函数头入口，正文不放自身元信息。
  注释必须以硬换行结束，不能吞掉正文或调用后缀。
- Source 与 DiagnosticPseudocode 明确区分。Error、不可表达特性或未满足编译要求
  不得被标成普通 Source；诊断文本必须保持在注释边界内。
- 依赖宿主环境的表示由公开选项提供；不猜运行时 API。
- 公开选项的默认值及前端消费点按 [项目约定](../../AGENTS.md) 同步。

## 排错

| 现象 | 首查位置 |
| --- | --- |
| 括号、分组或运算符错误 | emit/expr |
| 字符串/数字重编译失败 | emit/syntax |
| child 使用父函数名字 | emit/names 与 NameMap 切换 |
| 换行改变语句或注释边界 | emit/stmt、doc、render |
| 必需的 Luau pragma 缺失或被拒绝 | emit/luau_inlining，再追 HIR occurrence 生产者 |
| 诊断伪源码被当作源码 | 最终 feature 检查与 GeneratedChunkKind |

字面量边界、布局算法和具体编译器限制见实现与 Lua 样例；命令见 [调试手册](../debug.md)。
