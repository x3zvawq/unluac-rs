# Generate

Generate 把稳定 AST 与 NameMap 渲染为目标方言文本。
它负责语法发射和布局，不恢复控制结构、不分配名字、不补做可读性改写。

## 入口与数据流

入口：[generate/mod.rs](../../src/generate/mod.rs) 的 `generate_chunk`。

```text
AstModule + NameMap + 原 chunk 数字布局 + metadata + GenerateOptions
  -> emit -> Doc -> render -> GeneratedChunk { kind, source }
```

## 子处理层

| Owner（src/generate/） | 消费 | 生产与后继 |
| --- | --- | --- |
| [common.rs](../../src/generate/common.rs) | 输出请求 | GeneratedChunk、模式、布局与方言选项 |
| [emit/expr.rs](../../src/generate/emit/expr.rs) | AST 表达式 | 保留优先级和分组的 Doc |
| [emit/stmt.rs](../../src/generate/emit/stmt.rs) | AST 语句与块 | 语句边界、函数头与块 Doc |
| [emit/syntax.rs](../../src/generate/emit/syntax.rs) | 字面量与目标语法 | 字节转义、数字和 token 边界 |
| [emit/names.rs](../../src/generate/emit/names.rs) | binding 与函数上下文 | NameMap 中的最终名字 |
| [emit/luau_inlining.rs](../../src/generate/emit/luau_inlining.rs) | HIR 编译要求及最终 AST occurrence | 所需 Luau 编译合同的最终校验 |
| [doc.rs](../../src/generate/doc.rs) | emit 的布局树 | 与语义无关的布局 IR |
| [render.rs](../../src/generate/render.rs) | Doc 与行宽/缩进选项 | 最终字符串 |

## 稳定合同

- Generate 只输出 AST 已表达的语义，不猜 attribute、binding、value wrapper 或缺失节点。
- HIR 完整帧签发的 Luau 插值由 AST method-call 携带片段及固定参数，Generate 按原字节
  转义后输出反引号语法；它是单值表达式，不能转成独立调用语句，也不能按 prefix expression
  省略用于后续字段/方法访问的括号。模板识别及 CALL/COPY 证明不在输出层重复执行。
- emit 决定语法和括号，Doc/render 决定布局。折行和紧凑模式不能改变分组、求值顺序或语句边界。
  Luau 复合全局更新只按 AST 携带的 HIR 证明发射；标记的形状或目标方言不符时报告错误，
  不静默改成具有不同寄存器准备的普通赋值。
- 操作数顺序由 AST 决定；输出层不为好看交换比较两侧或改变逻辑树。
- 数字和字符串必须可重编译为同一值。可执行字面量使用原始 bytes；
  Parser 的 GBK 等解码视图只能用于展示，不替换字节值。
  数字往返以原 chunk 的数字模型为准：Generate 消费 Parser header 中的浮点宽度，
  将精确扩展为 f64 的 f32 常量按 f32 精度打印；关闭展示注释不影响此合同。
  这不承诺将 f32 程序迁移到 f64 VM 后仍有相同的算术行为。
- 函数名字从当前 NameMap 读取；进入 child 时切换函数上下文。
  `global function` 只按 AST 的显式声明来源发射，不从目标名字属于 global 推断声明。
- HIR 发布语义必需的 Luau 编译要求时，Generate 针对最终 AST 验证后才输出所需 pragma。
  该合同依赖 pinned 编译器，升级时须核对 `emit/luau_inlining.rs` 与相关测试；
  具体成本、阈值和封闭形状以实现为准。不能把编译要求当作可关闭的展示注释。
  编译要求绑定具体 occurrence、函数体和调用语境，不能推广为同形节点的许可。
  嵌套要求按所属函数分别验证，子作用域通过后才进入父作用域；外围函数调用还须具备不内联证明。
  没有自身编译要求的入口不重复核对无关兄弟函数；只读捕获 getter 仍逐 occurrence 核对
  比较输入的原 COPY 槽及最终只读函数体，外围成本按当前 AST 重新计算。
  `luau_inlining/captured_transfers.rs` 对捕获写入模板逐项核对捕获顺序、可写身份、
  表写入与返回标签；最终固定实参位置必须与 occurrence 的原结果槽一致。
  参数控制的嵌套循环可用逐路径成本下界证明保留 CALL；提前退出截断后缀，各节点单次访问。
  数值循环仍独立核对不展开条件，不能以函数不内联代替循环结构证明。
  字段谓词模板保留 Boolean 结果声明及共同返回，固定结果位置由原 occurrence 签证。
  外围参数回调表达式可在无常量折扣的封闭语法域核对完整成本；循环次数及无条件内层
  控制成本可分别排除循环展开，不能沿用已经改变的正文成本。
  捕获更新后的字面量 TEST 使用原条件槽，条件短路树不套用普通值表达式的额外结果槽。
  同一函数同时保留原 CALL 与条件专化展开体时，两类实参分别验证成本约束；
  不能因恢复调用必须内联，就允许其余原调用也被额外展开。
  `luau_inlining/constant_control.rs` 在最终 AST 重算 Boolean 参数特化轨迹和成本，
  与 HIR 的有序操作合同核对；外围数值循环的分配及观察成本下界也在当前树重新计算，
  不沿用 HIR 或前一轮改写的分析快照。
  完整动态函数的同次成本遍历还生成各数值循环的保守展开下界；所有变量折扣只用于降低
  循环下界，不能作为函数实参已常量化的事实。外围调用逐项核对动态实参及完整参数数目后，
  才以当前函数成本证明不额外内联。`luau_inlining/array_fold.rs` 则核对数组遍历的完整
  双返回模板和参数准备，保持其必须内联消失的独立合同。
  `luau_inlining/nested_search.rs` 核对最终双循环、条件状态更新和只读表实参，按共享成本证明
  常量边界调用会重新展开；外层比较仍使用原返回槽。外围循环的成本在当前 AST 上重算，
  包括表构造、闭包、索引写入及 builtin 实参，不能用遗漏操作的估算放宽展开限制。
  `luau_inlining/reset_counter.rs` 核对可写 Boolean 参数的完整循环及清零顺序；
  固定 Boolean 实参不能专化被重写的参数，动态成本分析没有使用形参真值 mask 时才允许这些写入。
  比较参数中的计数循环展开还须核对原结果槽与最终 callee、Boolean 和比较输入的分配关系；
  HIR 的源码帧证明不能被最终 AST 中不同的表达式位置替代。
  `luau_inlining/numeric_repeat.rs` 核对数值循环内条件 repeat 的完整函数体，并分别验证
  常量跳过索引、保留索引与动态退出条件的编译成本；原返回 COPY 指定每次调用的结果槽。
  `luau_inlining/guarded_counter.rs` 核对条件计数循环的完整函数体与常量、动态调用成本；
  成组 local 声明逐个消费原返回槽，按多赋值规则验证各 RHS 的固定单值语境。
  `luau_inlining/plain.rs` 在进入外围回调时重新消费 AST 的作用域写入事实，把独立函数的参数和运行时写入共同用于动态算术及
  math builtin 的常量折叠排除证明；子函数的同号 local 不继承外层身份或分析快照。
  多个计数遍历展开位于同一观察调用时，逐实参核对返回槽；固定单值尾调用保留
  单值语境。常量调用的内联与动态索引实参调用的保留分别由 `luau_inlining/generic_counter.rs` 验证。
  状态查找循环的展开还核对只读低槽实参与固定迭代体；原函数经表值逃逸后，
  索引调用按 pinned Luau 不解析该函数值的规则保持原 CALL。
  数值遍历调用复核 HIR 模板、只读捕获和两个出口的观察，并限制为数组实参及固定单结果声明。
  单次 repeat 查表和捕获状态的立即退出遍历分别由 `luau_inlining/repeat_lookup.rs` 与
  `luau_inlining/generic_break.rs` 核对最终函数体、调用宽度及内联成本；控制结构可合并，原检查仍须保留。
  常量选值调用核对单值逻辑返回、实参及固定结果宽度；在 generic-for 内按控制槽和
  迭代变量计算声明前缀，离开循环体后恢复外层作用域。
  同一参数与 nil/Boolean 比较的选值还保留完整比较链；最终模板的无折扣成本和调用的
  原结果槽单独核对，不把外围 Boolean 结果槽当作内嵌选值的返回位置。
  完整标量表达式调用还核对只读参数别名与最终单值返回；外围数值循环按当前表达式重算
  常量折扣和展开阈值，并逐层验证声明前缀及调用结果槽。
  参数比较写回另核对最终参数目标、比较、选值常量及返回身份；原实参初始化仍属于完整调用，
  Boolean 中间写与已合并的选值形式分别由 HIR 的原程序证明，不由 Generate 猜测写回关系。
  函数参数参与嵌套展开时，`luau_inlining/calling_values.rs` 消费逐 occurrence 的闭包依赖，
  验证最终函数体、捕获写入、只读函数绑定和实参写入性质；条件赋值及闭包声明参与当前循环成本计算。
  参数位置的匿名闭包使用原创建位置及方式验证身份，`luau_inlining/checked_reads.rs`
  核对标签断言、捕获计数和固定返回；只有对应 occurrence 的实参可消费这份依赖。
  nil guard 消去读取时消费独立的 `nil_guards` 合同；无闭包身份事实的第三实参只接受 nil。
  急切读取后共享结果的单返回合同独立核对读取标签、两次比较和同一 item 身份；
  返回判断被 nil 折叠也必须保留实际读取闭包依赖，不能沿用消去读取体的合同。
  `luau_inlining/observed_values.rs` 核对双标签读取及 trace 闭包的完整体，保留标签顺序、
  两层选值和全部比较；参数比较、只读值及实际读取闭包还须满足原槽展开合同。
  急切读取的双返回合同还核对固定两项声明、原结果槽及选择参数的常量专化；
  读取值在比较和第二返回中的身份必须一致，外围 builtin 观察仍独立核对。
  选择 false 的调用另记录被折叠的整数实参；同一闭包可用于不同选择，参数专化按 occurrence 核对。
  最终 AST 改变后须重新核对，未满足要求时显式失败，不输出伪装成功的 Source。
  常量控制函数的操作轨迹和成本按实际 Boolean 实参配置核对，同一函数可有多条轨迹；
  数值循环轨迹还核对最终循环体的展开成本，保留调用单独验证其不可内联性。
- 可选 proto 元信息属于对应函数的展示输出，注释不能改变源码语法或求值。
- Source 与 DiagnosticPseudocode 明确区分。Error、不可表达特性或未满足编译要求
  不得被标成普通 Source；诊断文本必须保持在注释边界内。
- 依赖宿主环境的表示由公开选项提供；不猜运行时 API。
- 公开选项的默认值及前端消费点按 [项目约定](../../AGENTS.md) 同步。

## 排错

| 现象 | 首查位置 |
| --- | --- |
| 括号、分组或运算符错误 | emit/expr |
| 字符串/数字重编译失败 | emit/syntax |
| child 使用父函数名字 | emit/names 与 NameMap 切换 |
| 换行改变语句或注释边界 | emit/stmt、doc、render |
| 必需的 Luau pragma 缺失或被拒绝 | emit/luau_inlining，再追 HIR occurrence 生产者 |
| 诊断伪源码被当作源码 | 最终 feature 检查与 GeneratedChunkKind |

字面量边界、布局算法和具体编译器限制见实现与 Lua 样例；命令见 [调试手册](../debug.md)。
