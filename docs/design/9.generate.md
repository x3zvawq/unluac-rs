# Generate

> **职责**：把稳定 AST 与 `NameMap` 渲染成目标方言源码；这是纯输出层。
>
> **不负责**：结构恢复、命名策略、可读性改写或补造缺失语法节点。

## 入口与数据流

```text
src/generate/mod.rs::generate_chunk

AstModule + NameMap + metadata + GenerateOptions
  -> emit/stmt.rs + emit/expr.rs
  -> Doc
  -> render.rs
  -> GeneratedChunk { kind, source }
```

## 模块 owner

| 文件 | 职责 |
| --- | --- |
| `common.rs` | `GeneratedChunk`、模式、布局与方言选项 |
| `doc.rs` | 语义无关的布局 IR |
| `emit/expr.rs` | 表达式、优先级与括号 |
| `emit/stmt.rs` | 语句和块 |
| `emit/syntax.rs` | 字面量、标点和跨节点语法规则 |
| `emit/names.rs` | 按函数上下文读取 `NameMap` |
| `render.rs` | 缩进、行宽、折行与最终字符串 |

## 稳定合同

- Generate 只输出 AST 已显式表达的语义；缺失的 attribute、binding、value wrapper 或语法节点不
  在这里猜测。
- emit 决定语法与优先级，Doc/render 只决定布局。折行、缩进和紧凑模式不能改变 AST 分组、
  求值顺序或语句边界。
  所有有序比较直接按 AST 关系和左右操作数发射，不根据显示复杂度交换成反向关系；
  常量右置与原快照先后由仍持有原 operand 事实的 HIR 决定。not Eq 的 ~= 仅改变符号，
  不交换操作数；not Lt/Le 不打印成其补集关系。
  一元/二元运算用显式任务栈发射，逐节点确定括号后合并 Doc 拼接；运算树保持原分组，
  不把同一深运算链继续递归传给布局树。块拼接直接移交已生成的 Doc，不复制嵌套子树；
  平铺检查消费剩余字符预算，已获完整平铺许可的子 Group 继承该模式，不重复测量。
- 数字与字符串表示必须可由目标编译器重编译为同一值；原始字节、整数/浮点类型、非有限值、
  运算符优先级与 lexer 边界均由 `emit/syntax.rs` 的集中规则处理。
  源码是 UTF-8 String，字符串字面量只有原始字节本身为 UTF-8 时才能直接输出文本或长括号；
  其它字节使用转义。Parser 解码出的 GBK 等文本视图用于展示，不能改变可执行字面量的字节值。
  引号选择的转义成本与实际发射必须消费同一原始字节视图。
- 进入嵌套函数时切换对应 `NameMap`，不能按模块平铺名字。
- 注释元数据的源码名沿用 HIR 的共享 `LuaString`，不逐函数复制文本；显示规则见
  [HIR 字符串合同](./5.hir.md)。注释关闭时不构建该元数据，最终输出仍为独立 String。
  开启注释时，每个实际输出的函数在参数表之后的同一行附加一次对应 proto 元信息，
  具名声明、局部函数值、表字段、参数和 IIFE 共用同一个函数头入口。
  原源码行范围以 `lines=start-end` 并入该注释；正文不承担自身元信息，避免与子函数混淆。
  不按 proto 全局去重，同一 proto 的多个定义出现位置各自保留说明。行注释使用 Doc 硬换行，
  紧凑布局也不能让注释吞掉正文、`end` 或调用后缀；关闭注释时沿用原语法和布局。
- 依赖宿主环境且 bytecode 无法恢复的表示必须由公开选项显式提供；Generate 不猜运行时 API。
- 最终 AST 含 Error 或目标不支持的 feature 时，产物标为 `DiagnosticPseudocode` 并逐行注释诊断，
  不能标成普通 `Source`。
- 所有公开 Generate 选项必须有唯一且实际生效的消费点；新增选项需同步 CLI、JS、WASM、Web 与
  README 合同。

具体字面量边界、分隔符选择和 Doc 布局策略见对应实现文件头与测试，不在本文维护 case 清单。

## 排错

| 症状 | 首查位置 |
| --- | --- |
| 括号或表达式分组错误 | `emit/expr.rs` |
| 字符串/数字无法重编译 | `emit/syntax.rs` |
| 名字来自错误函数 | `emit/names.rs` |
| 换行改变语句边界 | `emit/stmt.rs`、`doc.rs`、`render.rs` |
| 诊断内容逸出注释 | Error emit 与 `GeneratedChunkKind` 扫描 |
| 查看 Generate 结果 | `unluac --debug --dump generate <file>` |
