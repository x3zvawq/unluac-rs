# HIR

HIR 消费已经验证的 StructurePlan，把控制流、值流与捕获关系恢复为语义树，再消除机械中转。
本层负责表达式和源码生命周期证明；不重选结构候选，不决定最终名字或文本布局。

## 入口与数据流

入口：[analyze/mod.rs](../../src/hir/analyze/mod.rs) 的 `analyze_hir`。

```text
LoweredChunk + CFG/Graph/Dataflow + StructureFacts
  -> analyze：执行 plan、建立 binding、保存 provenance
  -> HirModule + ProtoPromotionFacts
  -> simplify：Normal / Deferred / Final 收敛
  -> 出口收尾：源码帧、方法事务、退出要求
  -> HirModule -> AST
```

proto arena 按父先子后分配，子函数完成分析的顺序与 arena 分配顺序不同。
跨函数分析通过显式 children/capture 身份导航，不能将连续下标范围当成词法子树。

## 核心合同

### Region 与 Edge

- HIR 只执行前层已经选定的 region、transfer、phi incoming 与 cleanup owner。
  缺失或冲突应回到 [Structure](3.structure.md#final-plan-合同) 修复。
- 原边上的并行值转移、循环阶段动作和清理保持各自身份及顺序；不能按语句相邻关系重建。
- 目标语法的必要要求汇入 `HirProto::exit_requirements`。AST 只消费这一出口，不旁路读取 plan。
- proto/plan 身份或消费数量不一致返回 HirError；不可用空块、默认值或临时 CFG 推断掩盖。

### Value 与 Binding

- `HirBinding` 是值引用与 capture 的共同身份；槽号、SSA Def 和源码 Local 是不同的域。
  相同值或相同槽不自动意味着同一个 binding。
- `HomeSlotKey` 包含槽位与 Close epoch。debug scope、cell 激活范围和闭包创建方式另有事实，
  不能从槽位相等推出捕获共享或生命周期等价。
- 固定结果与开放尾包保持显式宽度。表达式移动必须保持求值顺序、次数、错误与元方法观察。
- 逻辑值等价、正常返回值域、物理根存活和源码可重写权限分开证明。
  已知路径 truthiness 不授权删除原有检查或据此截断原有分支；保留恢复过程必需的结构整理。
  “没有读取”不等于可删除原写入，“结果为原始值”不等于求值无副作用。
- 空 debug 区间的声明与词法末端一起恢复；Bindings 消费原初始化 SSA 和闭合窗口证明，
  避免补回名字后延长 local、抬高后继求值槽。退出词法作用域不生成额外清槽操作。
- Promotion 保留原操作身份；simplify 更新绑定映射并使受影响的快照失效。
  被保留的 COPY、初始化或声明义务只能由其完整事务消费，后层不重新猜测。
- 分配模板、SETLIST 批次、CALL/SELF/FASTCALL、cleanup、Fresh/MayReuse 等协议不得提前压成普通语法。
- `LuaString` 的原始字节是身份，解码文本只用于名字或展示。

## Simplify 调度

唯一调度表是 [simplify/mod.rs](../../src/hir/simplify/mod.rs) 的 `PASS_DESCRIPTORS`，
依赖和失效标签以该表为准。共享 [scheduler.rs](../../src/scheduler.rs) 推进 Normal、Deferred、
Final；后续阶段产生新形状时重新触发依赖者，轮数耗尽显式失败。不要另建手工重复运行的 pass 链。

## 失败与输出边界

收敛后，`simplify_hir` 还按顺序完成源码物化/方法事务、展开帧、死布尔初始化、
普通方法语法许可和 `residuals::finalize_hir_exit_requirements`。
这些是出口收尾步骤，不是额外的固定点 pass；调用顺序见调度入口末尾。

出口向 AST 提供稳定 binding、capture、原根保留要求、语法权限与 typed exit requirements。
AST 不重新证明 VM 槽布局。proto 初始恢复失败可按 Permissive 协议记录 ProtoFailure；
全模块 simplify 失败不因此变成可恢复的单函数错误。

## 排错

| 现象 | 第一入口 | 继续追踪 |
| --- | --- | --- |
| 控制树或 phi 写错位 | analyze/structure | Structure 的 edge/emission/phi owner |
| 捕获身份或声明时点错误 | analyze/bindings、shared_closures | Dataflow、Promotion、Close epoch |
| 一行表达式被拆散 | 对应 simplify pass 的 before/after | 原 producer 是否在更早 pass 丢失，还是当前证明拒绝 |
| 调用/返回别名持续增长 | call_frames、source_frames | 原操作来源、COPY 身份与完整声明前缀 |
| 表字段或批次退化 | table_constructors | Transformer 分配合同及 Promotion 来源 |
| GC/弱表/闭包身份变化 | root_lifetimes、object_flow | Dataflow 原物理根与创建协议 |
| 最终还有 Decision/Unresolved | decision、residuals | 最早未完成的计划或值恢复 |

命令见 [调试手册](../debug.md)，断言见 [测试体系](11.test.md)。
具体 guard、方言槽距、可接受树形和回归反例只维护在实现与 Lua 样例中。
