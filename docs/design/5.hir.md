# HIR

HIR 消费已经验证的 StructurePlan，把控制流、值流与捕获关系恢复为语义树，再消除机械中转。
本层负责表达式和源码生命周期证明；不重选结构候选，不决定最终名字或文本布局。

## 入口与数据流

入口：[analyze/mod.rs](../../src/hir/analyze/mod.rs) 的 `analyze_hir`。

```text
LoweredChunk + CFG/Graph/Dataflow + StructureFacts
  -> analyze：执行 plan、建立 binding、保存 provenance
  -> HirModule + ProtoPromotionFacts
  -> simplify：Normal / Deferred / Final 收敛
  -> 出口收尾：源码帧、方法事务、退出要求
  -> HirModule -> AST
```

proto arena 按父先子后分配，子函数完成分析的顺序与 arena 分配顺序不同。
跨函数分析通过显式 children/capture 身份导航，不能将连续下标范围当成词法子树。

## 核心合同

### Region 与 Edge

- HIR 只执行前层已经选定的 region、transfer、phi incoming 与 cleanup owner。
  缺失或冲突应回到 [Structure](3.structure.md#final-plan-合同) 修复。
- 原边上的并行值转移、循环阶段动作和清理保持各自身份及顺序；不能按语句相邻关系重建。
- 合流转移在 HIR Assign 保留独立来源，提升和无改写的表达式提取继续传递；
  carried-local 只据未失效的入口状态消除重复转移，不把原 COPY 或 debug 初始化当作合流噪声。
  locals 提升前可消解所有 incoming 都来自同一只读参数的 Luau 纯 phi；整个 proto 的
  参数写入、引用捕获及独立 debug/root 身份仍阻止替换，原指令写入不由该规则退休。
  原 COPY 与 canonical 参数合流并存时，Promotion 的逐跳 MOVE 来源证明供 carried-local
  将原写接回结果身份；任何中间引用捕获都会中断该证明，原写的位置与 RHS 保持不变。
  Edge lowering 同样不得穿透可变 cell 的 MOVE 链读取初始化来源，须消费原 COPY 快照。
  同槽 synthetic phi 写回可并入已有目标的原写点，但必须保留目标声明，并通过路径写回验证。
  未提升 Temp 也可沿显式 phi 写回认回该声明：全部读写必须处于同一 owner 的词法后缀，
  并通过共享 CFG 的活跃性、并行写与协议干扰检查；原写入位置和 Def 来源继续保留。
- 目标语法的必要要求汇入 `HirProto::exit_requirements`。AST 只消费这一出口，不旁路读取 plan。
- proto/plan 身份或消费数量不一致返回 HirError；不可用空块、默认值或临时 CFG 推断掩盖。

### Value 与 Binding

- `HirBinding` 是值引用与 capture 的共同身份；槽号、SSA Def 和源码 Local 是不同的域。
- Luau 全局复合更新由完整赋值帧证明读取、运算结果和环境写共用原槽；HIR 赋值携带
  必须发射复合语法的事实，仍保留完整读取与二元式供分析。后续节点重建必须保留该事实，
  不能退回会增加 operand scratch、延长旧根寿命的普通赋值。
  相同值或相同槽不自动意味着同一个 binding。
- `HomeSlotKey` 包含槽位与 Close epoch。debug scope、cell 激活范围和闭包创建方式另有事实，
  不能从槽位相等推出捕获共享或生命周期等价。
  numeric-for 的源码声明前缀查询只证明连续槽布局；逐轮捕获可以重建不同 epoch 的 cell，
  因而固定 binding 槽号与唯一物理 home 分开表达，不向其它改写提供身份合并许可。
  比较指令及字段写的直接 local 输入由 lowering 记录该读取位置的可见 owner；完整帧可据此核对
  跨 epoch 的循环变量读取。此事实仅保留原读取，绑定被重写失效后不可沿用，也不签发 cell 退休。
  比较跨分支准备时保留原 use→Def 输入；完整帧据此消费 CALL 前缀，不能用当前槽位猜回 producer。
  比较的 phi 输入保留原消费位置，独立物化值与内部取值操作数均沿同一身份进入 Promotion；调用选值与比较帧消费同一归属，
  区分取值结果槽和仅作真假测试的 CALL 暂存槽，不因外层 DAG 包含多个谓词而丢弃内部帧。
  Luau 内外值树各自持有 Boolean 预写和结果槽，随完整操作数按序重发；结果声明继续保留时，
  其值语境标记不阻止收回匿名预写，真正退休结果仍须通过该绑定的保留约束。
  值决策入口的 MOVE 同样保留初值与结果 phi 的同槽关系；完整 initializer、比较及算术操作数
  消费这次准备并重发短路，不凭相邻 COPY 的外形合并独立快照。
  合流入口的结果 MOVE 独立保存 phi 与目标 Def 的关系；高槽求值、低槽写回可由完整
  initializer 共同重发，原 debug 目标及声明仍保留。前向合流可位于循环体内，回边 phi
  不领取当前准备区的 Boolean 初始化证明。
- 直接上值写回在 Assign 保留原 SETUPVAL 来源，Promotion 提供其 SSA 输入身份。
  native frame 据此把 Boolean 预写与完整 RHS 一起验证；合成赋值不继承该证书，
  目标改变或原输入身份合并后不可继续使用。
- 固定结果与开放尾包保持显式宽度。表达式移动必须保持求值顺序、次数、错误与元方法观察。
  Analyze 以原调用协议确定开放 producer 的唯一 consumer；FASTCALL fallback 的全局导入或
  保存库表字段读取属于同一协议，不能把普通 CALL 的 callee-first 顺序套到该开放尾上。
- 逻辑值等价、正常返回值域、物理根存活和源码可重写权限分开证明。
  Luau 的共享返回值分析可汇总未逃逸闭包的全部已知调用实参，细化参数入口；参数事实不继承
  调用者常量树的锚点。返回、存储、参数传递、捕获或合流丢失 callee 身份会关闭此证明。
  temp-inline 在快照有效时取得单结果 producer 的非资源证书，只撤销多余的保活要求，
  求值顺序、原写入与完整源码帧仍由各自 owner 验证；不按调用点重复分析函数体。
  PUC/LuaJIT 的 `debug.setlocal` 仍可改写未捕获绑定，不能套用这项词法写入证明。
  已知路径 truthiness 不授权删除原有检查或据此截断原有分支；保留恢复过程必需的结构整理。
  已恢复短路树中的稳定绑定检查也不能按代数公共因子合并；值等价验证不提供控制流证明。
  共同出口的恢复由原 Decision 图的边关系证明，不能在失去图身份后凭表达式相等重建。
  Boolean 测试与 Boolean 叶组成的值决策可复用同一控制图归约，结果仍须为 Boolean；
  先保留共享出口再恢复值，避免中途生成没有原槽来源的快照绑定。
  值表达式综合不靠重复条件或追加叶值测试来编码一般三元式；无法直接承载的选择保留控制树。
  true 字面量直接或经唯一 COPY 进入谓词时，同样保留原值写入及声明前缀；
  多定义 phi 的叶值仍属于比较物化协议，交给 Decision 与完整帧恢复，不逐叶冻结。
  “没有读取”不等于可删除原写入，“结果为原始值”不等于求值无副作用。
  已有目标的纯 binding 选值可恢复为单次短路检查，目标声明与原覆盖位置不变；
  带调用或运算的分支仍须由完整帧证明。连续匿名 nil 初始化与同槽空合流声明由
  locals 按 home/epoch 接回同一身份，保留每次原 nil 写与保活约束，不穿过实际求值。
- 空 debug 区间的声明与词法末端一起恢复；Bindings 消费原初始化 SSA 和闭合窗口证明，
  避免补回名字后延长 local、抬高后继求值槽。退出词法作用域不生成额外清槽操作。
  尾部 debug 作用域同时考虑目标编译器的函数边界：Lua 5.1 的函数级区间本就结束于
  隐式 RETURN 前，不额外引入 do/CLOSE；独立 cleanup 与嵌套块仍保留各自边界。
  这一边界同时约束 Bindings 的空区间窗口与后续尾部作用域物化，避免前层重复创建词法块。
  同一尾部终点的声明共用一个词法块，起点仍由各声明自身限定。
  仅恢复外层词法末端的事务可验证声明栈投影；原子块内容不变且临时身份没有跨块逃逸时，
  内层未恢复的 CALL 准备不应阻止外层同槽复用。改变求值或声明的事务仍须验证完整帧。
  词法窗口可完整包围 ValueDecision，但不能切入其内部；Emission 查询负责此边界，
  Bindings 仍独立证明原初始化、CFG 闭合和 debug 生命周期。
- 成组 local 提升可消费同一初始化入口、相同作用域窗口的 canonical debug 身份；
  SSA 初始化归属和完整写域继续约束声明组，不能仅按槽号相邻合并。
- debug scope 内的多次写可由 Bindings 统一到已证明的入口声明；声明所在的实际发射作用域
  仍须覆盖使用位置，包括 Structure 恢复的单次循环包装，不能只凭 CFG 入口判断词法可见性。
  debug 区间越过合成 SinglePass 的出口时，声明归属其外围源码作用域，初始化写仍在原点发射。
  goto 区域所有外部入口汇入同一首块且该块不在循环中时，其普通前缀同样可保留原声明；
  Emission 提供冻结布局与入口查询，Bindings 继续核对 debug、捕获和词法结束边界。
  跨回边的匿名 COPY holder 可接回函数入口已有的未读 nil 初始化，保留原清槽位置；
  其同槽 Boolean 退休写继续使用这份绑定，不再额外制造入口声明和替代写。
  nil/Boolean 写和未读的数字覆盖也可由支配全函数的原入口 nil 声明承接；Bindings 核对该槽全部
  Def 与 canonical Phi 的 home/epoch 和既有身份，后续 Boolean 读取及循环自反馈继续使用原声明。
  入口 nil 自身须在首次读取前已覆盖，避免把 CALL、iterator 或构造器的准备值误当作声明；
  参与值流的数字分支仍交给原表达式与并行合流 owner。
  原写入及检查均保留，不按 goto 路径推导常量删除。
  槽在前后用于 scratch 时，nil 开始的连续未读 Boolean 写组也可在原点建立独立绑定；
  原声明须支配各写点并包含其发射作用域，不穿过既有词法边界，末端由完整帧恢复消费。
  debug 入口恰在循环头时，从已证明的 carried phi 输入找回前置初始化，同时绑定初始化
  出边和区间内写入；不能把回边 phi 自身当成另一个源码声明。
  入口 MOVE 的快照若在函数退出前结束，仍由词法恢复决定其声明归属，不能延长为函数级身份。
  子函数的 debug 名称不建立创建点的局部绑定；Luau 字段闭包的推断函数名与变量表身份分开处理。
  Luau 展开调用的参数归属同时消费 Structure 的初始化末端和 exclusive 结束指令；只有
  完整展开帧、原初始化身份及同一 child 的形参匹配时，才将区间交回必须重新内联的调用。
  展开调用的参数与函数体准备由共享 FrameBuilder 消费；返回外层比较时恢复帧语境，
  保留同一事件游标。调用证书从最终候选树收集，与整批声明前缀及原根后缀一起提交。
  标量展开体还核对原 NOT 更新链、全局 callee 读取及高 CALL→低 COPY 的完整写域；
  必需内联的 child 保留原逐次更新边界，避免后续 AST 树化导致回编译删除显式操作。
  FASTCALL 同时核对原 builtin 身份及 direct 参数域，保留参数之后的 fallback 查找；
  已树化的 child 更新从原写入 home 恢复。立即 COPY 和后继比较属于同一展开帧，
  不能被独立赋值候选提前截断；后缀中的无捕获闭包声明仍按原位置和写域验证。
  caller 中复制的 child 局部 debug 区间仅在初始化身份、完整读写及结束位置匹配时
  形成未提交投影；同一 child 的最终内联证书必须消费全部原 CALL，才能将身份交回函数体。
  Luau 按值自捕获优先由独立结果 Def 持有递归身份；覆盖参数、循环 binding 或既有 cell 时
  仍建立独立快照。后续同槽定义不写入该自引用身份，AST 直接发射必需的 local-function 语法。
  独立结果同时登记原 home 与值身份；按值导出的闭包可在后继原帧复用该槽前结束词法域，
  仍需所有读取位于窗口内，并与完整调用/赋值准备共同验证源码前缀。
  捕获声明与独立 CLOSE 可跨内部条件；capture owner 以支配、闭合图区间和共同发射域
  证明窗口，不在基本块切换时丢弃尚未关闭的 cell。后续 locals 提升保留匿名循环状态的
  home 统一协议，同时核对 debug 身份，新声明不因复用 scratch 槽而并入外层物理根。
  同一 LOADNIL 或 VM Entry nil 跨越多层声明时，词法窗口同时记录初始化的槽分界；
  plan emission 按原 binding 拆分前导 nil 声明，再发射窗口内指令，不移动求值或增加写入。
  窗口输出的低槽 holder 以该分界核对父级声明深度，不能因整条初始化指令位于窗口起点
  就把它当作内层 local，或为 CLOSE 后的调用另造一份身份。
  普通 carried 状态仍由 capture owner 分配 cell，只有 numeric/generic-for 的源码 binding
  交给循环语法 owner；唯一 carried 入口在同 epoch 且支配全部捕获和写入时持有初始化声明，
  回边与出口 phi 复用该身份，逐轮 CLOSE 的内部 cell 保持独立。
  每轮先覆盖再捕获、因而没有活 carried phi 时，循环外入口字面量初始化仍可拥有
  共享 cell；必须证明初始化支配捕获且两者同属未关闭 epoch，不能外提逐轮激活。
  只读引用捕获若读取普通分支合流，已有初始化支配同一激活的所有捕获、写入和 phi 时，
  也由该 cell 接收原分支写回；不另物化只为承接 reaching phi 的捕获快照。
  原 CLOSURE 结果的引用自捕获由 locals 建立新身份，不按同槽继承旧调用临时量；已激活的
  cell 仍保持共享写回，旧匿名根在原覆盖端点释放，再由完整帧恢复消费其准备声明。
  旧匿名值先复制到仍活跃的高槽、低槽再原位接收 CLOSURE 时，locals 保留原声明并写回；
  两个绑定仍构成后继帧前缀，捕获与 debug 身份不借这种物理槽复用合并。
  分支内匿名 MOVE 可接回其原 SSA 覆盖的外层 Def；Promotion 提供同 home/epoch 的覆盖身份，
  locals 核对外层全部绑定版本及 debug/capture 边界，原写回位置不变；有独立 PhysicalRoot
  生命周期的组仍消费原覆盖/释放配对，不借同槽身份绕开释放义务。
  [locals/mapping.rs](../../src/hir/simplify/locals/mapping.rs) 随映射增量维护全部版本的
  home 摘要，子块退出时同步回滚；repeat 尾条件在 body 映射有效期内改写。
  非 TBC 的同源 RETURN/TAILCALL cleanup 由函数退出承接，返回值与调用准备不移到关闭之后；
  独立 CLOSE 及 debug 已确认的内层终点仍保留原窗口。关闭窗口中的 SSA 合流消费
  Dataflow 对相应槽域的闭合 phi 集合，内部重赋值不等于逃逸；条件初始化从共同控制头
  验证窗口，debug 初始化归属先于窗口划分。窗口外的读取和合流仍阻止身份收窄。
  已关闭旧 cell 或其它 SSA 版本的按值快照不阻止未捕获循环状态写回；仍需原回边定义、
  同 epoch 和当前版本未捕获的证明。按值捕获的 Phi 输入在捕获 owner 一次展开并共享。
  debug 已确认同一声明经过重赋值再被只读引用捕获时，也由捕获 owner 统一其写入身份，
  不把最终 Phi 与原声明拆开；声明位置仍由支配和 cell 激活窗口约束。剥离 debug 时，
  入口槽第一笔未读取的字面量初始化也可接收同 epoch 捕获 Phi 的分支写，保留原初始化位置。
  没有 LOADNIL 的入口 captured cell 以确切 Entry SSA 建立初始化归属；读取均在已闭合
  窗口内时，入口声明在窗口内部发射，已有 debug 绑定复用同一身份，不移到首次捕获处。
  没有独立关闭窗口且覆盖入口的 cell 同样在入口声明，保留其相对于高槽初始化的前缀顺序。
  入口绑定只拥有自己的值版本；同槽后续捕获仍参与 CLOSE 窗口分析，不能因已存在入口
  LocalId 而丢弃后续词法边界。
  RETURN 关闭的捕获同样可跨内部条件，以共同发射域和闭合图区间证明激活起点。
  函数入口或独立 CLOSE 与下一次 cell 激活之间的无捕获帧，在 Def/Phi、debug 身份和使用全部
  闭合时保留自己的词法窗口，避免旧声明占用后继 initializer 的准备槽；不添加清槽或 CLOSE。
  同一 LOADNIL 的捕获成员先统一初始化归属，再划分激活窗口，避免部分成员提前分流后
  将其余成员的赋值误作新声明。
- Promotion 保留原操作身份；simplify 更新绑定映射并使受影响的快照失效。
  locals 对直线词法块的外部输出复用 must-write 分析，在块前建立支配后续读取的绑定，
  不把这些结果留到 AST 才统一提升到函数入口。原根、捕获和 debug 身份继续约束复用。
  无读取的比较初始化可能没有 SSA phi；Bindings 消费冻结分支的互斥写入与同槽事实，
  为结果提供共同 Temp，交由 branch-values 恢复表达式；带 debug 时消费 Structure 的
  BranchInitializer scope 关联恢复名称及初始化边界，不伪造 SSA 读取。
- for binding 的分配和捕获共享所属块查询。numeric-for 的 control 前缀按发射位置属于
  本轮 body 尾部，继续使用同一源码 binding；generic-for 的下一次 iterator 调用不获此许可。
  generic-for body 内的 phi 若全部输入均为同一绑定在边末端的当前值，也消费该源码身份；
  合成边复制和 repeat 暂存不再另建 carrier，跨槽旧值快照仍独立保存。
- 原 Unary/Binary 操作的保留义务与 VM 观察事件分开。discard、常量控制与纯值综合不能仅凭值域删除原运算、检查或其控制路径；GC 查询仍只判断真实观察能力。
- 完整调用帧可按原顺序消费多槽 LOADNIL 的全部参数成员；整组只提交一个准备事件，
  缺失成员、debug 身份或残余读取不能随调用恢复一起消失。已完成的数组和常量模板
  仍按目标 VM 的原分配及字段暂存布局进入返回/参数帧，不以常量内容代替布局证明。
- 源码帧验证中的未物化 Temp 使当前词法块布局未知；只有整个 proto 均无读取或捕获时，
  才能在退出子块后恢复外层声明前缀。使用事实覆盖最后一个帧请求之后的后缀，不能
  用扫描窗口或子块结束推导逃逸身份消失。
- lowering 为两条边直接汇合、以及只读字面量临时的原 branch 保留 `HirIf.preserves_empty_test`；后者由 SSA 确认单节点 TEST 是该定义的唯一用途，不等待临时值内联。短路结果仍读取该值时由原值恢复合同处理。空臂、相同分支和值域均不授权删除受保护的 TEST；值分支表达式化和 AST 共同消费保留事实。两边无边效果时统一控制极性，保留原 subject 检查并使重编译收敛。
  环境访问归一化为 GlobalRef/Global 仍保留原读写来源；赋值帧据此验证无额外左值准备，
  RHS 在原槽求值，环境 cell 在原写入点读取，不能把它提前变成旧环境快照。
  被保留的 COPY、初始化或声明义务只能由其完整事务消费，后层不重新猜测。
  同槽状态合并须同步原 Def 到 Local 的身份映射；独占 producer 的失效证书另行退休，
  不能因展示身份合并而丢弃后续完整帧所需的原输入版本。根块后置 phi 仍由整图干扰和
  首次有效写证明认回支配它的已有声明，不要求两次声明相邻。
  调用输入依赖的低槽 COPY 链及其源定义由完整帧 owner 消费，普通内联不能先折叠
  caller 声明前缀，再要求后层仅凭末端 home 恢复缺失槽位。
  temp-inline 保留未读固定单结果 CALL 的确切覆盖；locals 据完整根事务决定接收槽和
  后续赋值的 binding。匿名 CALL 根被后继 callee 精确覆盖、且窗口身份不逃逸时，
  `locals/root_scopes` 在提升前结束旧声明域；原 CALL 结果槽随窗口保留，
  后续完整帧仍由 `native-call-frames` 核对准备事件及源码前缀，不把同槽复用当作永久 Local 身份。
  全局 callee 读取与低槽 callee COPY 共用该覆盖合同；词法边界包含原 callee/嵌套参数准备，
  FASTCALL 的前置参数留在下一帧。失败的字面量参数候选不占用外层窗口，调用下界由
  本块一次建立的区间索引查询，实际闭合性扫描仍保持窗口不重叠。
  可追溯原写入布局的表字段赋值可随窗口原序保留；它不引入声明，base/key/value 的读取
  仍参与身份闭合检查，不能将字段写入误作延长所有局部声明域的屏障。
  无独立 GC 身份的常量声明也可在同 home 的 callee 覆写处结束；窗口内调用必须仍在其上方，
  所有定义须封闭，捕获与 debug 身份仍交给各自的作用域 owner。
  CONCAT 输入准备和低槽写回同属完整赋值帧；Promotion 保留原结果与紧随的 MOVE，
  native owner 分别核对输入区、结果槽和既有目标，再原子收回机械副本。
- 原 LOADNIL 与 reaching initializer 在同一基本块内的捕获声明组保留连续槽身份；
  被该块支配的后续只读捕获也沿原初始化和写回绑定，避免前缀占位与捕获快照重复声明。
  Close epoch 和 debug 窗口仍独立约束身份。
- 分配模板、SETLIST 批次、CALL/SELF/FASTCALL、cleanup、Fresh/MayReuse 等协议不得提前压成普通语法。
- `LuaString` 的原始字节是身份，解码文本只用于名字或展示。

纯条件与值选择共用 Decision 的串并联图归约，先按共同出口消费唯一入边的子节点，
不先展开共享 continuation 再复制 guard。条件的真假终端只约束控制流；值选择的
CurrentValue、Boolean 预写及原根终点仍遵守独立的值帧合同。
残余 Decision 的控制物化继续消费局部归约图，终端写入只在选中后提交；整图无法折为
值表达式不影响内部条件恢复。`CurrentValue` 仍需要原测试值时不领取纯控制归约许可。
仅连接空叶或直接控制出口的树形残余 Decision 由 `eliminate-decisions` 直接物化控制树，
不创建 Boolean holder；每个原测试仍保留，共享子图与值结果继续遵守各自的合流合同。

Structure lowering 在 `HirRepeat.preserves_condition` 区分原条件与合成循环包装，
AST 继承这一事实；后续将原尾分支并入条件时同步标记。恒真值不构成删除原条件的授权，
只有不承载原检查的单次包装可由 AST 展平。

Luau 末次完整调用可与前方匿名标量声明的作用域末端共同恢复。调用 owner 只预览这一次调用的准备区，
作用域 owner 以当前值域证明待退出身份不持有资源、无引用捕获及后续读取，保留其中全部计算和原槽覆盖，
再验证调用回到实际形参前缀。新词法块使 `BlockStructure` 失效；该证明不外推到允许回调经
`debug.setlocal` 改写未捕获 local 的方言，也不删除原显式检查或初始化。

证明和提交属于同一个 owner。候选失败不发布部分删除；变化标签必须覆盖真实改动。
控制结构恢复先于子块会丢失 guard 形状的改写；共享遍历提供语句前序与后序入口，
各 pass 仍负责自己的候选证明。debug 窗口物化同时消费已有语法块的结束边界，
无附加动作的 while 回边已关闭 body 作用域，不为相同终点重复建立 do 块。
TBC 作用域物化同样区分函数域与内层域：通过完整活跃域验证、原 RETURN 配对且没有
独立 debug 终点的函数尾资源复用函数域，清理 origins 仍由同一事务消费。
完整帧消费匿名声明时，其原槽的后续写仍属于同一事务：恢复声明、Temp→Local 来源和
后继调用的源码前缀一起验证、提交，不能仅删除准备区后让未提升的原覆盖写流入死写清理。
同一绑定的多次准备共同参与声明恢复；预览拒绝时撤回全部相关事务，再验证剩余整批。
失败候选不阻断不依赖它的后续构造器，重试仍限于常数次完整扫描。
捕获分析对只读引用也发布显式 CLOSE 的独立激活，locals 不把新捕获值绑定到窗口外的
匿名 owner。无捕获声明段与后继声明、调用或词法块复用原首槽时，source-frames 可恢复旧段末端，
保留其外围仍活跃的声明。普通 CALL 与 Luau FASTCALL 均消费各自原帧的入口；旧声明不得仍有
窗口外读取，且须连同单结果 CALL 初始化和完整后缀一起验证。位置复用不要求新旧 cell 的 epoch 相同。
已提升 Local 的查找写入同样可以触发声明末端恢复；低槽外部表写消费原布局，
不打断段内最后读取的追踪。作用域结束不生成清零，后续原帧继续决定物理根覆盖时点。
同槽多次 Boolean 写同样计入声明的最后访问；后继低槽检查的两臂直接复用同一准备槽时，
可在分支前结束旧声明。动态 key 的一元/二元准备消费原操作类型及 Def 来源，完整前缀仍须验证。
Luau 的按值捕获保留独立快照身份；原 nil 与低槽 CLOSURE 写回可由同一外层声明承接，
高槽快照的词法末端仍由最后读取和后继原帧证明，不把 ByReference cell 当作快照退休。
闭包前的相邻匿名 COPY 也可恢复为同槽声明初始化，保留分配前的原覆盖；闭包后的独立 COPY
按原 Def 与现存语句核对其写入责任，声明归属与后继完整调用帧仍在同一预览中提交。
CALL 参数与固定结果查询按原调用索引定位 Def，再核对其可信物理槽；CLOSE 后的新 epoch
不阻止连续帧恢复。整组初始化仍逐项匹配结果 Def 与当前 Local 身份，不能合并不同 cell。
SETLIST 固定元素同样保留原 use→Def；构造器按元素版本消费准备区，不混入同 Local 后续复用的写域。
同批前序帧已经消费的根版本，可供后继帧接收其 `LocalRootRelease`；新写入与控制边界
使该交接失效，完整预览还须证明前序计划实际提交。RK 容量按各原操作之前的源码发射

Luau 低槽固定字段的字面量写由 Promotion 提供原 RHS scratch 入口，赋值事务与作用域
预览消费同一查询，保证收回临时声明后仍在原槽准备值，再完成字段写入。
固定字段的闭包 RHS 同样共享帧入口查询；目标为上值时，入口包含原 GETUPVAL 快照，
完整赋值保持目标读取先于 CLOSURE，AST 函数声明糖仍受该求值顺序约束。
Luau 的具名字段函数声明有相反的原求值顺序。native 帧单独验证闭包创建、全局目标读取和字段写，
以 `HirAssign.luau_function_declaration` 保存先 RHS 后目标的合同；共享遍历按此顺序访问，
AST build 必须直接生成函数声明，不依赖可选 sugar，也不能再当普通字段赋值收进构造器。
PUC 上值 RHS 也消费同一 SETTABLE 的单次输入 Def，目标快照与 RHS 读取在完整赋值中
按原顺序、原槽重发；SETTABUP 仍在写入点读取目标 cell，不伪造提前读取。
已完成 record 构造器进入外层帧时，字段原写来源仍用于核对表/全局/上值读取和闭包分配的
scratch；PUC 预分配、JIT 模板/索引式分配及 Luau 模板沿用原合同，闭包字段也消费原创建
Def 与 capture 可见性，上值字段消费原 SETTABLE value Def，不只按字段表达式的外形放行。
完整 PUC/JIT 构造帧按源码槽位重发，但分配与字段写仍匹配包含 Close epoch 的原 home；
嵌套表准备声明由其原分配 Def 授权退休，后继同 Local 的新声明仍由整批预览恢复。
构造器字段和数组元素的算术复用调用帧的原输入/结果槽证明；复合操作数按左右顺序读取，
常量保持原位置，Luau 显式准备另核对 use→Def。逐项写数组及模板的已合并字段沿同一事实
验证后接续剩余字段，完整提交仍核对原容量、模板键集合和批次边界。
部分合并的 Luau 模板先核对已树化字段的原 scratch，再接续后继字段写；未完成字段标记
始终交回构造器 owner 消费，不能把部分模板当作完整参数或返回表达式提交。
Luau 方法帧分开核对 receiver 求值与参数后的 COPY/方法查找，原协议、连续事件及完整后缀验证仍共同约束提交。
数组元素中的短路值同样受嵌套准备索引约束，独立 initializer 恢复不能提前消费其内部方法帧。
原方法协议证明结果仍被同槽 SELF 消费时，参数构造器不结束这段单次方法链；
源码身份和共享结果仍保留独立初始化，普通方法链由最外层完整帧统一验证。
数组输入和记录字段的原读取 Def 提供当前值版本的未捕获事实；后续同槽的新捕获不回溯生效，
实际捕获与后继绑定仍由整批声明预览检查。
Luau 的数组逻辑值沿用谓词与值叶的原槽协议；结构合成的 Boolean 包装恢复为短路选值，原生 NOT 来源仍受保护。
构造候选终点与嵌套准备索引共同消费原容量/模板键边界；后续方法安装等普通字段写
不能遮住已完整的 initializer。既有低槽的独立写入结束高槽构造候选，普通字段写随后交给
赋值帧 owner；索引式分配没有 hash 预留时，固定字符串字段同样不能占用构造准备区。
尚未填满的预分配与未解析的 key 仍保留在完整帧候选中，
不能用独立构造器的终点查询截断嵌套调用准备。Luau 已合并的显式数字字段按原逐写 scratch 验证，
与 SETLIST 的连续数组缓冲分开；LuaJIT 字段闭包沿同一赋值帧消费创建 Def 和 capture。
返回、构造器及算术帧复用原字段读取协议：直接 GETTABUP 消费原上值、常量或未改写的入口参数键和结果 home，
GETUPVAL→GETTABLE 消费本次 use→Def 的基址准备；目标快照先于 RHS 求值，
写回后的字段读取仍是独立操作，不能以算术结果替代。
Luau 动态索引保留结果槽后，复合 base 与 key 在相邻两个高槽依次准备；
读取帧按原来源消费二者，key 的回调不能导致 base 被重新求值。
record 末次写与尚未生效的 debug 声明共享原分配 Def 身份，构造器与调用帧消费同一查询；
后继同槽 capture 不回溯为本次初始化的屏障，实际绑定捕获及事件顺序仍须独立核对。
原 fixed 定义的引用捕获状态由 Promotion 统一发布，供操作结果、构造器元素及 temp-inline
消费；删除准备值时保留对实际捕获绑定的检查，不按整个 home 的未来或终止分支捕获一概
保留。原 home 合并或失效后不能继续使用原写入位置的未捕获证明。
被 Decision 吸收的内部定义也消费这份证明，未来的 capture 不能使未发射的初始化值
退化成尚未初始化的 cell 读取；入口 prefix 和已有开放引用仍保持绑定读取。
完整值赋值复用同一构造器布局证明，在原 freereg 求值后才安装到 local、全局或 upvalue；
消除临时声明不改变目标 cell 的写入时点，后续槽复用由统一 preview 核对。JIT/Luau
的闭包字段也消费同一完整布局证明；Luau 显式键占用的 scratch 与 value 创建槽分别保留。
Luau 的完整短路 RHS 与紧邻低槽 COPY 共同提交，逐叶验证比较及值读取，保留原目标 cell
的声明和写回时点，不因中间 phi 物化出额外 debug 身份。
CONCAT 声明和全局/upvalue 赋值消费同一原连续输入帧，分别核对结果与输入区；
Promotion 保留各输入在原指令处的 home/epoch，循环后复用的槽仍按完整身份核对，
缓冲区存在开放引用捕获时不签发普通重放许可。Luau 的独立结果槽也由该证明覆盖，
全局写另外核对其原 RHS home。
完整 RHS 帧已重建时，机械声明的 PhysicalFramePrefix 义务由同批前缀与值版本预览接管，
其它保留原因仍是屏障；后继同槽写不能继续借用已收回的声明。
构造器参数与紧邻的 CALL 结果写回属于同一事务，不能提前固定匿名结果的声明前缀。
Promotion 已标记为后继调用参数的结果继续留给外层帧，构造器候选不得提前截断它。
仅为物理根保活而没有普通读取的 CALL 结果仍保留独立绑定，可合并同槽 callee 初始化，
不能删除结果或把其后覆盖提前到回调之前。
CALL/FASTCALL 已树化到已有低槽的赋值 RHS 时，仍按原空闲区恢复完整参数；低槽目标保持已有身份。
CALL 向已打开的低槽捕获 cell 写回时，Promotion 保留原单结果给完整帧；目标 cell
仍可被回调改写，不能替代源槽根。后继帧仍从结果槽上方开始时，
保留该结果声明和 COPY，不能先合并低槽写回而丢掉后继 caller 的声明前缀。
后继独立 CLOSURE 声明或已有 callee 前缀事实也参与下界判断，避免忽略原槽复用
而额外保留旧结果；构造器字段闭包不能仅凭同槽赋值成为独立边界。
Promotion 按原指令保存固定多结果的连续写回次序与目标 cell；native-call-frames 将剩余
COPY 和合流转移一起匹配，完整恢复低槽赋值。Phi 的最终排列不能替代原 MOVE 写序，
源码前缀、debug 身份及后缀残余读写仍由同一事务验证。
调用型并行赋值及 nil 尾项赋值由 `promotion/copy_assignments` 保存快照、旧目标与完整写序，
`call_frames/native/assignments` 共同消费准备区和所有写回。PUC/JIT 的 RHS 栈与 Luau 的
冲突槽协议分别验证；debug 已绑定的后续 SSA 写同样发布 Temp→Local 身份，不能只记录初始化。
首项字面量或旧值快照、末项直接低槽写、首项 COPY 由同一原生帧重发；不能只把首项
内联到末次写回，使并列赋值在回编译中退成反序单写。双 nil 的方言批量写协议仍单独核对。
lowering 的绑定登记不合并来源槽，local home 仍由实际声明事实提供。
carried 的完整 result 写回事务删除局部声明时，原 Def 到 Local 的映射随整份身份迁移；
同轮迁移链在 pass 结束时批量解析，后继帧不消费已删除的 local。仅改写局部 use 不能迁移定义身份。
carried-local 也可将尾部合流身份接回顺序区间中的原同槽 COPY；原 Temp 无读取或捕获、
目标身份在间隔内不可观察、来源未被改写时，保留原写点并删除重复转移。
低槽 RETURN 写回保留目标 COPY，高槽返回准备保留低槽输入；Locals 在分配写回声明前
安排同槽的原 nil 初始化，再用现有最后读取与身份规则复用该声明。多目标 Phi 不能将
低槽逐次计算改成高槽并行 RHS，表达式内联与完整写回恢复分别持有各自证明。
Luau 并列声明的 RHS 共用暂存区；声明帧 owner 按原 CALL/MOVE、构造写或 Boolean 操作数布局恢复整组，
连同结果身份和后缀复用一并预览，不能先提交单个 RHS 改变后续求值槽。
共同生效的 debug 声明组由同一 owner 消费原初始化身份、区间和连续目标槽，逐项验证 RHS 帧后整体提交；
独立声明的不同生效边界仍保留，AST 不凭相邻位置合并 debug 绑定。
字面量上值赋值沿用原准备区和写回顺序；LOADNIL 批次与 Lua 5.1 入口清零由各自原始事实证明，
不因准备值尚未提升为 local 而跳过完整帧恢复。
JIT/Luau 的纯条件比较操作数由原 scratch 帧消费，Boolean 结果仍写原槽；临时声明在 HIR
退休后，后继 CALL/FASTCALL 才能使用正确的源码前缀，不能只依赖 AST 的表达式内联。
Luau 条件选值的两臂若能各自恢复完整原帧，且匿名合流结果只供紧邻条件读取，
`call_frames/native/conditional` 可在同一 preview 中消费合流声明与两臂准备，签发原生
if 表达式。共享 DAG、条件值复用和分支内未消费的事件仍保留显式控制语句；AST 不补做帧证明。
两臂结果已树化时也可恢复条件 initializer。Boolean 物化还可连同前方同槽计算一起恢复，
比较输入和结果写回由共享 FrameBuilder 证明，仍在整批 preview 中核对声明前缀及后续根；
不能仅凭 true/false 两臂越过帧保留约束。debug scope 必须从原合流结果开始，提前生效的
声明仍独立保留。Promotion 对普通分支及 Decision 吸收的内部 phi 共建单判定索引，
短路备用臂按原 COPY 记录 local/参数身份，读取仍发生在被选中的分支，不能提前为 CALL 前快照。
比较方向整理后仍沿用原谓词的结果身份；locals 的分支合流按 debug scope 选择绑定，
不能因新声明复用原 home 就接到旧匿名 operand 身份上。
短路 RHS 的求值帧与现存赋值目标分开核对：谓词叶、值叶沿用原 CALL 槽，完整结果才写回
低槽目标；恢复表达式不提前更新捕获 cell，也不改变其 debug 声明身份。
共享分析应在当前不可变快照上建立，不能将旧 SSA、词法位置或对象流结果套到新树上。

## 失败与输出边界

源码物化先于固定批次降低参与 Final 收敛；任一 Final pass 改写后立即回到 Normal/Deferred，
让完整帧消费新恢复的作用域和表达式，前层再次稳定后才审理后续 Final pass。
展开帧恢复在固定表批次降低之前参与 Final 收敛，防止 SETLIST 身份丢失；已发布的 occurrence
不会重复恢复，成功后让普通 consumers 继续处理新树。
收敛后，`simplify_hir` 还按顺序完成方法事务与前缀发布、
普通方法语法许可和 `residuals::finalize_hir_exit_requirements`。
这些是出口收尾步骤，不是额外的固定点 pass；调用顺序见调度入口末尾。

Luau 新闭包同时保留原函数体模板来源与 Fresh 创建方式。展开帧可据模板匹配现存工厂，
但同模板不代表同一个闭包对象；每次原创建仍须重发。按值捕获的常量参数准备与结果声明、
后续调用帧共同提交，Generate 核对工厂体和指定内联语境后才发射编译要求。嵌套工厂还须匹配
内外层捕获映射，函数体中的固定宽度调用与 caller 帧原子恢复；相等的值不能合并不同
词法捕获来源，Generate 同时核对两层函数体的内联条件。
直线快照工厂可包含捕获前后的调用：展开体按原操作、debug 身份和统一槽偏移与函数体
配对，原 nil 声明、按值捕获及低槽结果 COPY 一起恢复。独立调用与完整词法包装由计划
显式认领，内部声明仍接受后缀使用验证；预备帧及其 Promotion 事实只在整批验证通过后发布。
Generate 复核函数体的保守内联成本与独立结果声明槽，确保恢复的调用不新增运行时栈帧。
单参数快照、条件方法调用和字段返回由 `native/expanded/conditional_methods` 配对现存
函数体：保留短路树中的每次读取与检查，核对只读实参复用、内部槽偏移和低槽返回。
debug local 与原 SSA 临时值消费同一证明；条件及其子语句随完整后缀原子退休。
只读捕获产生 callable 后返回标签与调用结果的展开体，按固定双结果帧恢复。内部资源绑定、
高槽 CALL/COPY、低槽结果及后续并列写回共同接受前缀证明；不能独立删除资源 COPY。
外围 FASTCALL 的已恢复参数树仍重放原协议；原常量比较可复用现存恒等模板保留显式检查，
Generate 拒绝会随 O2 折叠消失的直接常量比较。
高槽 debug 形参的初始化与结束区间若严格对应恒等调用展开，可在原子提交中恢复为
必须内联的匿名恒等表达式。形参继承原名称，资源调用仍在原高槽执行并写回低槽；
合成 proto 不继承物理来源，Generate 单独核对其函数体、无捕获和内联语境。
共享闭包搬回 synthetic factory 时继续携带 reusable 模板身份，包装函数自身不冒充原创建。
owner 模板同时记录其内部显式整数捕获；O2 将外层常量复制到 owner 后，只在每个 occurrence
同样来自相等的显式整数定义时配对，并在 factory 内恢复该捕获。父级初始化仍保留原位，
该按值身份证明不推广到 NaN、引用捕获或资源值。单个 NaN 快照直接读取不逃逸的合成表；
多快照仍共享一次表分配，分配与读取均保留在原 capture 锚点。
若入口已有未使用的恒等函数，封闭的 Luau O2 标量初始化可复用它作为必须内联的宏，
避免 NaN 屏障增加声明槽；同一事务保持整数捕获和单用 Boolean TEST 的编译不透明性。
HIR 发布完整 occurrence 集，Generate 核对恒等函数、共享工厂和外围语法后才发射 O2 要求；
不为普通控制臂、循环或未证明的函数体启用该合同。
在同一封闭编译域内，shared-closure owner 可同时认领工厂的原事件前缀与固定参数，
以连续槽位、内部 SSA 使用和所有 occurrence 的完整匹配为提交边界。工厂签名、事件参数、
两层 reusable 模板、内联成本及每次单结果声明的原槽由 Generate 再核对；调用必须展开，
不能额外建立运行时栈帧或平移事件的临时槽。
嵌套 owner 同时参与另一组共享恢复时，全局发布型工厂按完整原体合并两份计划：
内部工厂调用、发布写入和返回闭包共同提交，全部展开实例都被覆盖后才消费独立 owner。
Generate 核对内外层调用成本、发布字段和三个 reusable 模板；普通全局读取只在已证明的
发布字段域内进入这份 O2 合同。比较准备沿同一 use→Def 接受环境读取归一化后的 GlobalRef，
后续完整帧仍核对读取槽、事件顺序和唯一消费，不能仅凭全局名称移动快照。
源码帧恢复结束的匿名 nil 作用域若随后紧邻同 home 的空声明，可让该声明承接原 LOADNIL
初始化；沿用完整原定义组，不合并 debug 身份，也不移动或省略中间事件。
Boolean 比较写回既有匿名 local 时，Promotion 核对原结果和两侧操作数槽；高于结果槽的
已声明操作数也可直接读取。新声明的比较结果仍使用原低槽前缀限制，不沿用赋值许可。
整数捕获工厂的结构化后缀与普通帧共用 DFS 坐标、控制槽和词法前缀验证；数值循环还须
在 HIR 与最终 AST 分别证明 O2 不会展开，不能因为工厂调用可内联就默认外围控制流不变。
已恢复的 do 作用域只提供词法边界，不视作额外 VM 事件；展开帧仍逐项验证块内语句，
不能因忽略包装而跳过调用、声明或出口的重放义务。
Luau 泛型循环的源码声明前缀还包含编译器为单个迭代变量保留的第二个结果槽；
Promotion 在循环帧中单独记录该占位，前缀验证不把它伪装成 local 或 nil 初始化。

条件输入的 CALL 结果若仍占据分支入口的声明前缀，`temp-inline` 在树化前保留原 Def 的
PhysicalFramePrefix；真值条件与显式比较消费同一分支入口证明。完整调用帧的槽位与
保留约束检查使用同一原操作 Def，不能把 Local 后续值版本的保留义务回溯到旧值。
Luau 只读形参 COPY 分析按开放结果包的实际覆盖下界排除受影响形参；高槽开放尾
不使所有低槽形参事实失效，MOVE 链仍须逐 Def 排除改写与引用捕获。

出口向 AST 提供稳定 binding、capture、原根保留要求、语法权限与 typed exit requirements。
AST 不重新证明 VM 槽布局。proto 初始恢复失败可按 Permissive 协议记录 ProtoFailure；
全模块 simplify 失败不因此变成可恢复的单函数错误。

## 排错

| 现象 | 第一入口 | 继续追踪 |
| --- | --- | --- |
| 控制树或 phi 写错位 | analyze/structure | Structure 的 edge/emission/phi owner |
| 捕获身份或声明时点错误 | analyze/bindings、shared_closures | Dataflow、Promotion、Close epoch |
| 一行表达式被拆散 | 对应 simplify pass 的 before/after | 原 producer 是否在更早 pass 丢失，还是当前证明拒绝 |
| 调用/返回别名持续增长 | call_frames、source_frames | 原操作来源、COPY 身份与完整声明前缀 |
| 表字段或批次退化 | table_constructors | Transformer 分配合同及 Promotion 来源 |
| GC/弱表/闭包身份变化 | root_lifetimes、object_flow | Dataflow 原物理根与创建协议 |
| 最终还有未签发的 Decision/Unresolved | decision、residuals | 最早未完成的计划或值恢复 |
