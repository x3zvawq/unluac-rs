# HIR

HIR 消费已经验证的 StructurePlan，把控制流、值流与捕获关系恢复为语义树，再消除机械中转。
本层负责表达式和源码生命周期证明；不重选结构候选，不决定最终名字或文本布局。

## 入口与数据流

入口：[analyze/mod.rs](../../src/hir/analyze/mod.rs) 的 `analyze_hir`。

```text
LoweredChunk + CFG/Graph/Dataflow + StructureFacts
  -> analyze：执行 plan、建立 binding、保存 provenance
  -> HirModule + ProtoPromotionFacts
  -> simplify：Normal / Deferred / Final 收敛
  -> 出口收尾：源码帧、方法事务、退出要求
  -> HirModule -> AST
```

proto arena 按父先子后分配，子函数完成分析的顺序与 arena 分配顺序不同。
跨函数分析通过显式 children/capture 身份导航，不能将连续下标范围当成词法子树。

## 核心合同

### Region 与 Edge

- HIR 执行 Structure 已验证的 region、transfer、phi incoming、emission 与 cleanup 归属，
  不重新选择候选；计划缺失或冲突回到 [Structure](3.structure.md#final-plan-合同) 处理。
- 原边的并行值转移、循环阶段动作与清理保留独立来源和求值顺序。
  合成 carrier 与原指令写入分开表达，不能仅因形状相同就删除原操作。
- 值决策的结果写入与旧 debug holder 退休分别消费原 phi 覆盖事实；只有全路径覆盖且
  决策内无根观察时，lowering 才能在结果之后发射统一退休，不能靠后层表达式外形猜测。
  当前 HIR 值域证明可撤销非资源 binding 的合成退休标记，不授权删除原字节码写入。
- `HirEmissionFacts` 提供计划到实际发射域的投影，Bindings 消费该投影确定声明的词法归属。
- Plan lowering 标识无正文及回边动作的条件前缀包装；调用帧和声明恢复稳定后，
  `tail-loop-conditions` 消费该归属选择尾条件语法，并重新验证当前控制、资源与表达式边界。
- 无条件循环包装消费最终边转移及祖先 break 传播事实；仅剩末尾正常退出时发射词法块，
  保持声明、清理与显式跳转归属，不重新识别 CFG 循环或删去原条件操作。
- proto/plan 身份或消费数量不一致返回 `HirError`，不发布半成品成功产物。

### Value 与 Binding

- `HirBinding` 统一值引用与 capture 身份；SSA Def、物理槽、源码 Local 分属不同身份域。
- `HomeSlotKey` 保存槽位与 Close epoch；debug scope、capture 模式和 cell 激活范围独立保留。
  同槽不等于同一 binding，值相等不等于生命周期相同。循环出口仍打开的引用捕获
  由 Dataflow 的程序点状态确认，epoch 不得在真实关闭之前切断其身份。
- 绑定分析按原 SSA 值签发未捕获事实，经 promotion 供调用初始化边界消费；同槽后继值的
  捕获不回溯到旧值，定义合并或原 home 失效后不再使用该证书。
- 固定结果与开放尾包保持显式宽度；表达式改写保留原求值次数、顺序、错误和元方法观察。
- 内嵌值决策保留独立原 phi 的结果身份；完整值图的归约可传递该身份，子图投影清除它。
  残余决策物化只复用仍有可信 home、尚未提升的结果，声明位置仍交给 Locals 判定。
- 完整布尔值帧向比较叶传递结果的 `HomeSlotKey`，同时保留槽号与 Close epoch；
  循环内的比较初始化不能在消费时把已证明的结果重新当作零 epoch scratch。
- Decision 的表达式前缀只写新 Local 或独立未提升的结果 Temp，原语句目标另行提交。
  线性化前一次收集当前 proto 的引用捕获；未捕获的 Local/Param 读取可跨这些前缀，
  捕获绑定、上值及缺少独立写入证明的 Temp 仍保留有序快照。此阶段不引入新捕获。
- 逻辑值域、原操作的保留义务、物理根存活与源码改写权限分别证明。
  已知真值或没有读取不授权删除原计算、检查、初始化及声明。
  Promotion 根据原 SSA 的入口值、指令及 phi 消费记录未读字面量初始化；已有定义、
  参数或变参槽的覆盖不取得独立声明许可。源码帧稳定后，Locals 在最终清理前消费
  尚未合并、未捕获且 home 有效的剩余定义，向后层发布 `SourceInitialization` 保留义务。
  当前无读取不等于原定义未读，已经消费的常量准备不由这份事实恢复为声明。
- Bindings 持有初始化、debug 与捕获的声明归属；未使用和零长度 debug 区间仍保留源码身份。
  词法窗口消费同一 epoch 下完整的捕获激活范围，以及 Emission 的独立发射边界；
  不得扩大原活动区间，也不以额外清槽替代原生命周期。
  带提前离域的窗口使用 GraphFacts 的单入口/出口查询，并逐出口核对原关闭协议；
  分支私有 Close 不替代正常路径的词法终点。
  COPY 声明若需在作用域末端交给匿名保活身份，交接读取当前 Local 后结束旧槽
  的根责任；交接与清槽之间没有观察，后续寿命仍由原覆盖端点约束。
  再编译后的显式末端清槽由词法窗口 owner 消费，核对声明、完整写域与捕获边界，
  恢复原 debug 结束点，不把已清空的声明延长到后继回调。
  捕获窗口的生产者合并共享关闭协议的可信 debug 初始化前缀，向词法发射和闭包输出绑定
  发布同一个源码窗口；cell 激活时点仍独立保留，不随窗口起点扩展。
  Locals 消费该初始化身份确定声明入口；同一 debug 区间的后续写入不能让此前的合流结果
  引用尚未声明的 Local，声明归属与后续 RHS 的求值位置分别保留。
  无 debug 的原槽快照写回由捕获 owner 沿 SSA 来源确定较早的初始化，连同中间写入
  归于同一 cell；只在同块、同 epoch 且尚未打开引用捕获的窗口内使用，有 debug 时沿用所属声明事实。
  repeat 本轮入口的独立标量初始化沿用同一 debug 声明，供 body 与尾条件共享；
  已外提的前缀、捕获及提前结束的词法窗口不从该入口事实取得改写权限。
  repeat 正常出口的计算结果已共址于当前 carried 状态时，暂存复用该身份，独立结果 phi 仍按协议提交。
  正常出口、提前退出与结果读取共同消费最终绑定投影，包括后续确认的参数身份。
  repeat 出口暂存在 debug 与捕获绑定分配完成后核对统一 Local 归属；正常和提前出口
  均已属于同一词法身份时，lowering 直接消费该身份，独立快照仍保留原暂存协议。
- 固定 `VARARG` 的原覆盖前驱由 Promotion 从 SSA 定义记录；Locals 只沿仍有效的
  同一 home/epoch 接回已有声明，保留被覆盖的显式初始化。新 debug 身份及捕获边界
  不由这条覆盖事实推断。
  CALL 的同槽结果也沿原覆盖前驱接回已证明的绑定；结果没有读取只影响新匿名声明的
  建立，不取消已有绑定上的写入。完整调用帧保留结果初始化及后续显式覆盖。
  原标量常量写也保留实际覆盖前驱；循环的统一入口将该初始化来源投影到 carrier，
  避免 seed 内联后丢失写回身份。Locals 仍核对旧版本最后使用及当前声明归属，
  不借同槽号合并新的 debug/capture 身份；定义合并失效时对应来源一同退休。
  标量与子域输出共同维护已计划绑定的最后需求索引；原 MOVE 与字面量写的精确覆盖可接回
  已结束需求的匿名外层声明，前轮已发布的 Temp→Local 身份也参与判定；原交换帧证明的
  COPY 写回可接回当前块的低槽声明，普通寄存器复用不等于源码身份连续。
  来源 cell 的原位读取与穿透来源链分属不同证明；字符串覆盖不扩大 GC-inert 根释放的值域。
  完整变参包的高槽结果、COPY 目标与旧低槽定义由 Promotion 的 copy-assignment owner
  一起记录；Locals 验证当前读写和完整源码前缀后，原子恢复声明及重赋值。Local 身份
  与原 scratch 写域分开保存，不能把高低槽合成一个模糊 home。
  原交换帧同时约束快照及其来源 COPY；temp-inline 不单独移动它们，完整赋值帧在
  身份物化后核对原写序与后续读取，不能把高槽快照误认成低槽输入声明。
  并列 CALL 的 scratch 起点来自原 RHS 位置，独立于低槽目标之间或之后的存活声明。
  PUC/JIT 已完成 RHS 后的低槽写按原逆序发布，标量重复目标同样保留全部原写。
- Promotion 保留原操作与值版本的来源，向 simplify 提供查询；身份改写同步更新映射，
  不能把某个版本的事实推广到同一 Local 的所有历史版本。
  调用和表分配结果共享 Dataflow 的无观察覆盖终点；末次读取、未捕获与全部同 home/epoch
  端点共同限定原根的后缀。构造器仍须验证当前 producer 身份、字段求值顺序和内容，
  不能把这条覆盖证书当作任意移动分配的许可；定义合并会同步退休相关端点事实。
  上值写回区分寄存器输入与指令内嵌字面量；后者保留原值而没有 home，
  完整赋值帧按方言写回顺序消费，不能为常量补造准备槽。
  单次调用或查表结果与备用值的短路选择共用原 predicate/phi 事实；输入、分支 COPY
  和合流槽分别保留，完整帧再验证当前操作及准备顺序，不能把输入槽直接当成结果槽。
  Locals 的显式跳转入口前缀消费原根的完整 frame-end 事实；当前声明支配关系与后续
  写入仍分别验证，带提前覆盖端点的事务不能借纯 scope-end 证明延长生命周期。
  后缀匿名准备仍由完整表达式帧消费，保活事实本身不赋予源码声明身份。
  Ignore CALL 的直接参数 callee COPY 同样交给完整调用帧恢复；旧槽已清空不证明
  调用可以平移。尚未消费的准备义务随身份提升传给 AST，保留返回后调用者可观察的
  残根覆盖窗口；固定及开放结果由原值帧 owner 处理，不继承 callee 的临时占位义务。
  原 nil 初始化、高槽分配与低槽 COPY 可共同确定调用覆盖前的声明窗口；比较分支的存在
  不阻止扫描此前的直线窗口。高槽比较准备写回既有低槽时，原 Boolean 结果身份和完整
  输入帧共同验证，合成 NOT 保留值极性，不能新建结果声明改变准备槽；仍位于后继调用
  准备区的结果继续由完整 CALL/FASTCALL 或展开帧消费。
  Temp-inline 在原 COPY 身份尚未提升前消费无事件的紧邻覆盖证明，将无读取、无源码
  身份的单结果调用恢复为调用语句；调用和原覆盖都保留，不给后继源码前缀留下未知声明。
  单次运算 Def、合并后的绑定及原写入槽分别保存；唯一 Def 查询不接受循环 carrier，
  完整写回帧则可核对同一来源的绑定、全部原写入与当前目标，保留已有声明。
  Locals 新建身份时保留所有输入共同证明的无物理槽事实；已有身份或未知来源不能
  借新绑定初始化规则消除物理来源，合成声明也仍占用生成源码的局部槽。
  父域已声明的非循环 Entry(nil) 合流绑定可承接子域同 home/epoch 的完整写域；
  词法映射按作用域增量维护该 owner，debug、捕获身份及额外写域继续阻止复用。
  返回输入证书同时覆盖固定包和开放包的固定前缀，边界来自 Dataflow 的开放 producer；
  多个 RETURN 共用布局时只发布共同成员与 Def。原 LOADNIL 组可由声明或原位赋值承载，
  完整返回帧与旧声明作用域共同预览，仍在原返回槽重发覆盖后再求值开放尾部。
  操作输入证书也保留参数入口值的 COPY 结果身份；完整赋值帧据此共同恢复计算左值、
  RHS 准备及上值/表字段写回，证书本身不授权改变求值位置或退休物理根。
- 分配、方法调用、开放包、闭包创建和 cleanup 保持显式协议，直到所属 owner 完整消费。
  debug-scopes 物化 debug 尾区间时保留块内的显式 cleanup 终点，由资源 owner 统一消费各出口。
  close-scopes 提交词法资源作用域时，同步退休标签上该 origin 的待消费 cleanup；
  未提交的 origin 保持原边义务，后续跳转整理消费当前合同而非已经完成的清理请求。
  source-frame-materializations 依据原 Entry(nil) 或显式 nil 前驱及紧邻 COPY 恢复低槽接收者的声明前缀；
  死临时清理先保留这类原 nil 前驱供声明事务审理；完整构造帧仍在原高槽分配并消费原 COPY，
  与后继使用一起验证后原子提交，未消费的前缀交回最终清理。
  分配前的完整 nil 组也保留到声明事务；Lua 5.1 省略的首部 nil 前缀由 Promotion
  依据原首条分配与非参数入口清零事实发布，不能用于后来的同槽分配。循环控制输入
  不与旧标量声明合并，generic-for 的原控制帧可作为旧声明段的结束边界；恢复仍须
  同时通过读写末端、捕获及整批源码前缀验证。
  COPY 根在结构化 proto 根块已有支配首写时，沿用该处初始化；入口 nil 只用于仍缺少
  词法初始化证明的身份。读取、捕获与释放都参与首次出现判断，显式跳转不借用此证明。
  Locals 的纯身份提升在 Assign 和 LocalDecl 上保留循环初始化写的 occurrence；声明绑定
  改变或 Decision 拆出新的求值前缀时失效。native-call-frames 根据当前值包、原 CALL/COPY
  来源及控制槽布局，共同消费固定值包或调用初始化准备与 dispatch 根释放。单独的写回
  恢复不认领仍属于循环头的 COPY，提交仍须通过整批声明前缀及后继使用验证。
  Locals 的根作用域 owner 以原覆盖配对结束匿名声明，CALL 结果和表对象分别消费原调用与分配 home；资源激活和 cleanup 分隔候选区，
  已结构化且 body 为直线写/调用的 generic-for、while 和 repeat 可整体留在区内；
  循环自己的单臂退出 guard 仍位于原位置，不退出外部候选窗口，所有临时定义仍须无逃逸；
  只含 Boolean 临时写或直接表字段写的嵌套分支也可留在窗口内，两臂的定义、写域和
  全部读取共同验证，条件及字段写的原执行位置不变。缺少本层直接调用端点的块不重复建立根索引。
  已有声明可留在扫描区，但不能被包入新窗口；未完成的表构造及其它控制结构继续保留整块，不能按未知节点切断协议。
  源码前缀分析消费 TBC 配对已确认的整个 Temp 声明包，按原 home 计入词法槽；
  Temp 身份本身不代表未知声明，离开作用域后不再保有这项声明事实。
  完整帧中的 LOADNIL 批次可保持 Temp 或已物化的多绑定声明；消费点的原输入 Def
  逐项核对同一批次、槽位及顺序，全部成员消费后才退休一次写入事件，声明形状本身不授权改写。
  Luau 末参数及循环初始化预留的结果区也约束内层数组缓冲；已合并构造器的字段、
  批次布局与尚未合并的写表事务共用该边界，不能在树化后退回表槽的紧邻位置。
  analyze 为 COPY 根的合成释放写保留原覆盖指令、独立单结果 Def 及被释放身份，
  与 dispatch 端点共用 HIR 释放来源模型；Locals 的纯身份改写保留该来源，改变写入
  形状则不得沿用。完整调用及数值循环头按各自的准备证书核对覆盖端点，共享释放
  校验并重发原写入；旧根退休不能脱离端点所属的完整帧，提交仍须通过整批
  源码前缀校验；尚未消费的释放不能因原声明退休而重新生成一条 nil 声明。
  lowering 标记合成副本根的入口初始化，Promotion 保留原 COPY 与词法 holder 的交接身份。
  完整帧可联合消费 seed、作用域交接及全部退休事件，由原 COPY 槽继续保活；声明来源、
  当前交接或整批前缀证明不足时撤回该帧。holder 保持无物理槽身份，不冒充原 COPY 的 home。
  Locals 若已将相邻的旧根释放与无观察的 Boolean 或绑定 COPY 写合并为同一 binding/home，根 owner
  可由该无观察写承担退休；撤销合成 nil 时同时保留原覆盖义务，不能再独立删除实际写入。
  Boolean 值语境与 COPY 根覆盖分别发布保留原因；完整帧仍须证明重发原写，不能借绑定同名内联。
  未知 home、独立释放对象及原显式 nil 不属于这项身份合并。
  CALL 的开放 VARARG 尾由 Promotion 保留唯一原包来源及尾槽，覆盖 FASTCALL 的
  callee 准备交接。调用与构造器共用开放尾帧证明；消费时保留原 builtin 协议、
  不可变 callee 快照和参数求值域，不以最终省略号外形反推原包。
  开放返回尾按原 CALL 结果协议区分普通开放结果与 TAILCALL；资源 cleanup 阻止尾调用时，
  完整帧仍可恢复参数准备，但保留普通 CALL、开放宽度及返回后的关闭顺序。
  整批前缀冲突时，返回候选可由原声明栈证明其必要前缀，并撤回消耗这些声明的较早候选；
  修改候选集合后重新验证整个预览，不把原快照的通过结果直接当作提交许可。
  普通 Local 的重声明携带同一缺失身份的全部消费来源。前缀分析记录声明顺序反转，
  以原声明栈验证后继请求后撤回相关来源，再由整批重建判断后续调用。
- Promotion 消费 Structure 的原程序点资源活动事实，区分普通固定定义与 TBC 活动槽写入、
  注册值。完整帧只按仍可信的原输入 Def/home 使用此证明，并保留当前准备区的资源边界；
  后来的同槽激活不回溯保护早先定义，home 合并失效或输入身份不足时不授权消费。
- Promotion 从冻结条件及互斥 Boolean 写回中保留完整结果的上值读取身份和准备 home。
  Native 帧只在对应结果内消费这些读取，并核对当前短路树、调用事件及声明前缀；
  不能凭同名上值或逻辑表达式外形推断准备槽。结果或输入定义合并、home 失效后证书失效。
- PUC/JIT 的批量 nil 准备与末项低槽直写、逆序 COPY 由 Promotion 记录为同一赋值帧。
  Native 只消费仍对应原 Def/home 的完整批次，保留目标绑定和写回顺序；准备声明、
  全部覆盖及当前源码前缀一起验证和提交，定义合并或 home 失效后不沿用原证书。
  并列索引目标与单目标共用原 key Def 的准备证明；完整帧区分寄存器表快照与 SETTABUP
  的写入时 cell 读取，按方言消费全部左值及 RHS 的事件顺序。
  匿名多结果 CALL 的词法末端由 Locals 联合认领全部结果 home；只在完整闭合窗口内恢复
  作用域，保留跨观察点的全部结果根，不把同次返回的 owner 拆开退休。
  固定多结果的低槽写回还复用原 COPY 前驱作为声明 seed；Locals 在 HIR 中连接未读初始化、
  接收结果与后续清槽，避免各阶段分别物化出不相干的绑定。
- Lua 5.5 global 声明由 analyze 认领完整的 RHS 与逆序 probe/store；固定前缀和尾调用
  的原输入 Def 记录在 Promotion，native-call-frames 据此共同恢复准备区。该事实绑定原
  CALL 来源与连续槽，当前值包及其写域仍须匹配；不授权拆开尚未认领的宽目标环境快照。
  HIR 声明同时保留首个 probe 的来源，调用帧扫描由原结果槽识别其前方的独立初始化边界；
  RHS 改写不移动 probe/store，候选仍须通过完整调用帧与声明前缀验证。
  初始化 carrier 消费完毕后，`branch-control` 可退休只剩完整 global 初始化的机械词法包装；
  HIR 保留运行事务，源码 global 权限及其作用域由 AST 重建，不能互相代用。
  单目标值初始化由协议 owner 保留 probe 与 store 的关联，Promotion 复用原 store
  输入证书提供 RHS Def、值及 home。完整帧可消费仍相邻的字面量准备，保留 probe/store
  顺序；旧 Local 曾承载的资源身份不因此整体清除，后继复用仍按声明 epoch 联合验证。
- Luau 已展开的调用由 `expanded-source-frames` 配对现存函数体、原操作来源及高输入/低结果帧，
  和后继声明前缀一起提交。条件专化只认领实际留下的路径，不反推已消去的原实参值；
  恢复调用携带必须再次内联消失的 occurrence 合同，交给 Generate 在最终 AST 上验证。
- `LuaString` 的原始字节是语义值；解码文本仅用于命名和展示。

### 共享事实与事务

已有完整查表操作布局证明的 Decision 保留共同结果槽与共享 continuation，等待声明帧稳定；
其它 Decision 仍按原 Deferred 边界物化。Final 重新取得当前候选与前缀事实，未通过者同次物化。
查表短路恢复在原操作布局与实际源码声明前缀共同通过时提交；这项完整帧证明不表示
单次测试的旧结果根已结束，也不能供后续改写脱离该帧使用。

共享分析只对应当前不可变快照。树、绑定或语句位置改变后，相关索引和证明必须失效；
原 VM 事实通过 Promotion 的来源查询消费，当前 HIR 的控制与对象事实由本层分析持有。
动态索引准备事实同时覆盖读取和写入，表操作的 key 即使树化也保留原 use→Def 与 home；
完整帧按实际 producer 区分算术结果与布尔合流，不能以当前表达式类别代替原输入身份。
Promotion 同时保存各 phi 入边共同覆盖的原初始 Def；源码帧恢复消费这项关系及当前绑定映射，
在完整前缀事务中接回初始化声明。结果与后续写回合并不改变原覆盖关系，初始 Def 失去独立身份时则失效。
前序声明被消费而使后继赋值成为新声明时，预览同时记录原声明的消费者并重证 initializer 帧。
新帧不成立则撤回造成身份缺失的消费者；成功查询只对当前预览有效，facts 更新后重新取得。
二元输入经 COPY 读取循环结果时，Promotion 保留该 use 对应的原目标 Def、来源绑定投影及两端 home；
准备值与 COPY 一起核对，不能把来源 phi 的合并误作原低槽写消失。展开帧消费者再验证当前控制结构、
全部原操作及后继前缀，整段退休循环时同时消费入口和末端条件坐标。
查表同时保留键的原 SSA 读取版本；该身份允许多次使用，与单次使用的可树化准备证书分开。
循环未更新的 Def 可沿块入口唯一 COPY 写回低槽；展开帧仍需核对当前绑定、读取范围与完整 home。

repeat 的退出暂存优先消费 Structure 已证明的条件入口循环状态身份，以及结果合流后冻结的
祖先 carried binding。嵌套入口发生原槽更新时，绑定层结合 Dataflow 的直接覆盖关系与
slot epoch 证明身份延续；独立暂存仍由绑定层显式分配。结果合并分别收集 break、可经条件退出的
continue 和正常完成路径，精确写回可覆盖并行快照，但必须保留其它赋值、capture、物理根与原状态更新的责任。

候选证明、预览和提交归同一 owner。跨语句事务同时承担准备、写回、声明及后继使用的义务，
失败不发布部分删除；成功后以变化标签重新调度消费者。具体接受条件与反例留在实现附近。

## 失败与输出边界

Normal、Deferred、Final 共同收敛后，出口收尾发布方法语法许可、源码前缀要求和
`HirProto::exit_requirements`。调度顺序以 `simplify/mod.rs` 为唯一来源。

AST 接收稳定 binding、capture、生命周期保留要求及具体 occurrence 的语法权限，
不重新证明 VM 槽布局。依赖目标编译行为的恢复通过显式编译要求交给 Generate，
由其在最终 AST 上验证；要求不能降为可关闭的展示注释。

proto 初始恢复失败可按 Permissive 合同记录 `ProtoFailure`；全模块 simplify 失败
仍属于模块错误。未获合法源码表示的残余节点显式进入退出要求，不由后层猜测补齐。

## 排错

| 现象 | 第一入口 | 继续追踪 |
| --- | --- | --- |
| 控制树或 phi 写错位 | analyze/structure | Structure 的 edge/emission/phi owner |
| 捕获身份或声明时点错误 | analyze/bindings、shared_closures | Dataflow、Promotion、Close epoch |
| 一行表达式被拆散 | 对应 simplify pass 的 before/after | 原 producer 是否在更早 pass 丢失，还是当前证明拒绝 |
| 调用/返回别名持续增长 | call_frames、source_frames | 原操作来源、COPY 身份与完整声明前缀 |
| 表字段或批次退化 | table_constructors | Transformer 分配合同及 Promotion 来源 |
| GC/弱表/闭包身份变化 | root_lifetimes、object_flow | Dataflow 原物理根与创建协议 |
| 最终还有未签发的 Decision/Unresolved | decision、residuals | 最早未完成的计划或值恢复 |

命令见 [调试手册](../debug.md)，断言见 [测试体系](11.test.md)。
