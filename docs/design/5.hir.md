# HIR

HIR 消费已经验证的 StructurePlan，把控制流、值流与捕获关系恢复为语义树，再消除机械中转。
本层负责表达式和源码生命周期证明；不重选结构候选，不决定最终名字或文本布局。

## 入口与数据流

入口：[analyze/mod.rs](../../src/hir/analyze/mod.rs) 的 `analyze_hir`。

```text
LoweredChunk + CFG/Graph/Dataflow + StructureFacts
  -> analyze：执行 plan、建立 binding、保存 provenance
  -> HirModule + ProtoPromotionFacts
  -> simplify：Normal / Deferred / Final 收敛
  -> 出口收尾：源码帧、方法事务、退出要求
  -> HirModule -> AST
```

proto arena 按父先子后分配，子函数完成分析的顺序与 arena 分配顺序不同。
跨函数分析通过显式 children/capture 身份导航，不能将连续下标范围当成词法子树。

## 核心合同

### Region 与 Edge

- HIR 执行 Structure 已验证的 region、transfer、phi incoming、emission 与 cleanup 归属，
  不重新选择候选；计划缺失或冲突回到 [Structure](3.structure.md#final-plan-合同) 处理。
- 原边的并行值转移、循环阶段动作与清理保留独立来源和求值顺序。
  合成 carrier 与原指令写入分开表达，不能仅因形状相同就删除原操作。
- `HirEmissionFacts` 提供计划到实际发射域的投影，Bindings 消费该投影确定声明的词法归属。
- proto/plan 身份或消费数量不一致返回 `HirError`，不发布半成品成功产物。

### Value 与 Binding

- `HirBinding` 统一值引用与 capture 身份；SSA Def、物理槽、源码 Local 分属不同身份域。
- `HomeSlotKey` 保存槽位与 Close epoch；debug scope、capture 模式和 cell 激活范围独立保留。
  同槽不等于同一 binding，值相等不等于生命周期相同。
- 固定结果与开放尾包保持显式宽度；表达式改写保留原求值次数、顺序、错误和元方法观察。
- 逻辑值域、原操作的保留义务、物理根存活与源码改写权限分别证明。
  已知真值或没有读取不授权删除原计算、检查、初始化及声明。
- Bindings 持有初始化、debug 与捕获的声明归属；未使用和零长度 debug 区间仍保留源码身份。
  词法窗口不得扩大原活动区间，也不以额外清槽替代原生命周期。
- Promotion 保留原操作与值版本的来源，向 simplify 提供查询；身份改写同步更新映射，
  不能把某个版本的事实推广到同一 Local 的所有历史版本。
- 分配、方法调用、开放包、闭包创建和 cleanup 保持显式协议，直到所属 owner 完整消费。
- `LuaString` 的原始字节是语义值；解码文本仅用于命名和展示。

共享分析只对应当前不可变快照。树、绑定或语句位置改变后，相关索引和证明必须失效；
原 VM 事实通过 Promotion 的来源查询消费，当前 HIR 的控制与对象事实由本层分析持有。

候选证明、预览和提交归同一 owner。跨语句事务同时承担准备、写回、声明及后继使用的义务，
失败不发布部分删除；成功后以变化标签重新调度消费者。具体接受条件与反例留在实现附近。

## 失败与输出边界

Normal、Deferred、Final 共同收敛后，出口收尾发布方法语法许可、源码前缀要求和
`HirProto::exit_requirements`。调度顺序以 `simplify/mod.rs` 为唯一来源。

AST 接收稳定 binding、capture、生命周期保留要求及具体 occurrence 的语法权限，
不重新证明 VM 槽布局。依赖目标编译行为的恢复通过显式编译要求交给 Generate，
由其在最终 AST 上验证；要求不能降为可关闭的展示注释。

proto 初始恢复失败可按 Permissive 合同记录 `ProtoFailure`；全模块 simplify 失败
仍属于模块错误。未获合法源码表示的残余节点显式进入退出要求，不由后层猜测补齐。

## 排错

| 现象 | 第一入口 | 继续追踪 |
| --- | --- | --- |
| 控制树或 phi 写错位 | analyze/structure | Structure 的 edge/emission/phi owner |
| 捕获身份或声明时点错误 | analyze/bindings、shared_closures | Dataflow、Promotion、Close epoch |
| 一行表达式被拆散 | 对应 simplify pass 的 before/after | 原 producer 是否在更早 pass 丢失，还是当前证明拒绝 |
| 调用/返回别名持续增长 | call_frames、source_frames | 原操作来源、COPY 身份与完整声明前缀 |
| 表字段或批次退化 | table_constructors | Transformer 分配合同及 Promotion 来源 |
| GC/弱表/闭包身份变化 | root_lifetimes、object_flow | Dataflow 原物理根与创建协议 |
| 最终还有未签发的 Decision/Unresolved | decision、residuals | 最早未完成的计划或值恢复 |

命令见 [调试手册](../debug.md)，断言见 [测试体系](11.test.md)。
具体 guard、方言槽距、可接受树形和回归反例只维护在实现与 Lua 样例中。
