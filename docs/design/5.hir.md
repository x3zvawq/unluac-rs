# HIR

HIR 消费已经验证的 StructurePlan，把控制流、值流与捕获关系恢复为语义树，再消除机械中转。
本层负责表达式和源码生命周期证明；不重选结构候选，不决定最终名字或文本布局。

## 入口与数据流

入口：[analyze/mod.rs](../../src/hir/analyze/mod.rs) 的 `analyze_hir`。

```text
LoweredChunk + CFG/Graph/Dataflow + StructureFacts
  -> analyze：执行 plan、建立 binding、保存 provenance
  -> HirModule + ProtoPromotionFacts
  -> simplify：Normal / Deferred / Final 收敛
  -> 出口收尾：源码帧、方法事务、退出要求
  -> HirModule -> AST
```

proto arena 按父先子后分配，子函数完成分析的顺序与 arena 分配顺序不同。
跨函数分析通过显式 children/capture 身份导航，不能将连续下标范围当成词法子树。

## 核心合同

### Region 与 Edge

HIR 执行 Structure 已验证的 region、edge transfer、phi incoming、emission 与 cleanup
归属，不重新选择控制结构。计划缺失或冲突回到 [Structure](3.structure.md#final-plan-合同)。
原边的并行值转移、循环阶段动作和清理保留各自来源及求值顺序，合成 carrier 与原指令写入分开表达。

`HirEmissionFacts` 将计划投影到实际发射域，Bindings 据此确定声明的词法归属。
循环状态、条件准备和正常/提前出口继续消费冻结的计划身份，不能从当前表达式外形重建归属。
proto/plan 身份或消费数量不一致返回 `HirError`，不发布半成品成功产物。

### Value 与 Binding

| 事实 | 生产者与含义 | 消费约定 |
| --- | --- | --- |
| `HirBinding` | Bindings 建立 Param、Local、Temp、Upvalue 与 capture 关系 | SSA Def、物理槽、源码绑定属于不同身份域；不能按同号互换 |
| `HomeSlotKey` | Promotion 保存原槽与 Close epoch | 同槽不等于同一绑定；值相等不等于生命周期相同 |
| 声明与初始化归属 | Bindings 消费 debug、SSA、capture 和 emission | 未使用及零长度 debug 区间仍可能有源码身份；活动区间与初始化身份分别保留 |
| 原操作与值版本 | Promotion 将原指令、Def/Phi、COPY、输入和结果映射到当前绑定 | 按具体消费点查询；一个值版本的证明不能推广到该 Local 的全部历史版本 |
| 固定结果与开放尾包 | 表达式 lowering 消费前层值包协议 | 宽度、单值调整、尾调用与普通返回保持显式 |
| 值决策与循环状态 | Structure 计划及 HIR lowering | 合流结果、入口值、边写回与当前绑定分别保留；不能以某一入边代替完整 phi |
| 分配、方法、闭包、全局声明及 cleanup | 对应协议 lowering | 显式保存身份、顺序和消费义务，直到所属恢复事务完整接管 |

原字节码可确认的求值次数、顺序、错误、元方法观察、写入及声明属于保真约定。
逻辑值域、物理根存活和源码改写权限分别证明；已知真值或当前没有读取不授权删除原操作。
`LuaString` 的原始 bytes 是语义值，解码文本仅用于命名和展示。

### 生命周期与原来源

Dataflow 持有原 VM 的逻辑读取、物理覆盖、观察点及 Capture/Close 程序点状态；
HIR 把它们映射到源码声明、捕获 cell 和根保留区间。逻辑使用结束、物理槽被覆写、
源码 local 离域是不同事件，不能互相替代。资源关闭、闭包创建及引用/按值捕获仍遵守原协议。

Promotion 负责原来源与当前绑定之间的映射及其有效性。完整身份迁移时同步更新来源；
仅替换局部使用不等于迁移整个定义。定义退休、home 失效或关闭边界变化后，相应证明不得继续使用。
当前树的读写、支配、逃逸与词法范围由 HIR 共享分析持有，不从旧 SSA 快照推断当前树形。

### 完整源码帧与下游权限

完整帧恢复将原操作的准备、求值、结果、写回和声明前后缀作为同一事务证明。
原 home 说明物理来源，`source_frames` 核对当前源码声明布局；两者不能互相替代。
恢复调用、赋值、构造器或展开体时，必须同时满足值包、capture、根、资源及后继使用的义务。
具体方言的槽布局、候选形状和帧匹配规则由对应实现维护。

源码帧向后层发布 `PhysicalFramePrefix` 等保留要求；原初始化的保真要求通过
`SourceInitialization` 等事实传递。方法、构造器、闭包创建和编译要求绑定具体 occurrence，
不是同形节点的通用许可。AST 消费权限，Generate 在最终 AST 上核对目标编译要求；
任何一层都不能仅因文本更简洁而绕过这些约定。

### 共享事实与事务

原 VM 事实通过 Promotion 查询；当前 HIR 的控制、值、对象与声明布局由以下 owner 提供。
共享分析描述所依赖的不可变快照，不自动授予改写权限。

| Owner | 生产的事实 / 能力 | 消费者与有效边界 |
| --- | --- | --- |
| [value_facts.rs](../../src/hir/value_facts.rs)、[value_semantics.rs](../../src/value_semantics.rs) | 正常结果值域与原始值语义 | 逻辑、Decision、内联；不代替事件和根证明 |
| [expr_safety.rs](../../src/hir/expr_safety.rs) | 当前方言的表达式安全分类 | 表达式移动、复制与删除 |
| [simplify/lexical_cfg.rs](../../src/hir/simplify/lexical_cfg.rs) | 当前树的控制、支配与词法跳转关系 | 对象流、生命周期、声明归属及前缀；控制或词法布局变化后失效 |
| [simplify/object_flow.rs](../../src/hir/simplify/object_flow.rs)、[object_flow/](../../src/hir/simplify/object_flow/) | 对象持有、逃逸、capture 效果及正常返回摘要 | 构造器、根与完整帧；效果输入变化后重建 |
| [simplify/root_lifetimes.rs](../../src/hir/simplify/root_lifetimes.rs) | 原覆盖/观察到当前根保留义务的映射 | 内联、构造器、repeat；来源或当前身份失效后撤销 |

| [simplify/call_frames/](../../src/hir/simplify/call_frames/) | 原操作到完整表达式/赋值帧的统一 builder | 调用、返回、条件、写回及展开体恢复 |
| [simplify/table_constructors/](../../src/hir/simplify/table_constructors/) | 分配、字段与批次的构造计划 | 消费共享 binding、root、效果及分配事实 |
| [table_layout.rs](../../src/hir/table_layout.rs)、[value_semantics/table.rs](../../src/value_semantics/table.rs) | 表分配与目标编译器字段求值约束 | 构造器、完整帧及后层投影共用；树化不抹掉原批次协议 |
| [simplify/method_protocol.rs](../../src/hir/simplify/method_protocol.rs)、[method_rewrite_transactions.rs](../../src/hir/simplify/method_rewrite_transactions.rs) | 方法来源及完整事务 | 方法恢复与 AST 语法许可 |
| [luau_inlining.rs](../../src/hir/luau_inlining.rs)、[luau_inlining/](../../src/hir/luau_inlining/) | 展开体恢复的显式编译合同 | HIR 签发，Generate 按最终 AST 验证 |
| [simplify/syntax_budget.rs](../../src/hir/simplify/syntax_budget.rs) | 目标语法预算 | 内联与完整帧；按当前候选查询 |
| [visit.rs](../../src/hir/visit.rs)、[traverse.rs](../../src/hir/traverse.rs) | 子节点与 capture 遍历语义 | 当前 proto 分析不隐式进入 child body |
| [rewrite.rs](../../src/hir/rewrite.rs)、[simplify/walk.rs](../../src/hir/simplify/walk.rs) | 定点代换与通用 rewrite | pass 在共享遍历上补充自身证明 |
| [simplify/stmt_plan.rs](../../src/hir/simplify/stmt_plan.rs)、[label_refs.rs](../../src/hir/simplify/label_refs.rs) | 语句计划与词法引用查询 | 批次提交及作用域调整；位置索引不跨改写复用 |

候选证明、预览与提交属于同一 owner。跨语句事务须覆盖全部准备、写回、声明及后继使用，
失败不发布部分删除；成功后以变化标签重新调度消费者。延后候选仍须保留明确的来源和未消费义务，
最终处理重新取得当前事实，不能把上一轮的成功查询当作提交凭证。

树、绑定、语句坐标或 capture 改变时，使依赖它们的分析失效。仅更新保留元数据且未改变
效果输入和节点身份时，调度器可以保留模块效果快照；随后实际改树仍须刷新。
这项边界由调度 owner 维护，不是跨 proto、跨树版本缓存的许可。

## 失败与输出边界

Normal、Deferred、Final 共同收敛后，出口收尾发布方法语法许可、源码前缀要求和
`HirProto::exit_requirements`。调度顺序以 `simplify/mod.rs` 为唯一来源。

AST 接收稳定 binding、capture、生命周期保留要求及具体 occurrence 的语法权限，
不重新证明 VM 槽布局。依赖目标编译行为的恢复通过显式编译要求交给 Generate，
由其在最终 AST 上验证；要求不能降为可关闭的展示注释。

proto 初始恢复失败可按 Permissive 合同记录 `ProtoFailure`；全模块 simplify 失败
仍属于模块错误。未获合法源码表示的残余节点显式进入退出要求，不由后层猜测补齐。

## 排错

| 现象 | 第一入口 | 继续追踪 |
| --- | --- | --- |
| 控制树或 phi 写错位 | analyze/structure | Structure 的 edge/emission/phi owner |
| 捕获身份或声明时点错误 | analyze/bindings、shared_closures | Dataflow、Promotion、Close epoch |
| 一行表达式被拆散 | 对应 simplify pass 的 before/after | 原 producer 是否在更早 pass 丢失，还是当前证明拒绝 |
| 调用/返回别名持续增长 | call_frames、source_frames | 原操作来源、COPY 身份与完整声明前缀 |
| 表字段或批次退化 | table_constructors | Transformer 分配合同及 Promotion 来源 |
| GC/弱表/闭包身份变化 | root_lifetimes、object_flow | Dataflow 原物理根与创建协议 |
| 最终还有未签发的 Decision/Unresolved | decision、residuals | 最早未完成的计划或值恢复 |

命令见 [调试手册](../debug.md)，断言见 [测试体系](11.test.md)。
具体 guard、方言槽距、可接受树形和回归反例只维护在实现与 Lua 样例中。
