# 2. Transformer（方言无关 Low-IR）

> **职责**：将各具体方言的 `RawChunk` 翻译为统一的寄存器级 `LowInstr` 序列，显式保留语言级 VM 协议与原始来源映射。
> **不负责**：切分基本块、构建 SSA、控制流结构化或表达式树化。

本层实现位于 `src/transformer/`，保持协议边界纯粹：只发布真实影响语言级语义的协议事实，不为下游臆造物理栈帧元数据。

## 入口与数据流

```text
RawChunk
  ──→ dialect lowerer（puc_lua / lua51 / luajit / luau）
  ──→ LoweredChunk { header, main: LoweredProto }
```

核心入口位于 `src/transformer/mod.rs`（`lower_chunk` / `lower_raw_chunk`）。

## 模块组织

```text
src/transformer/
  common.rs              统一 LowInstr、Reg、ValueOperand、ValuePack/ResultPack、LoweringMap
  debug_locals.rs        各版本 debug local 坐标归一与活动区间查询
  operands.rs            typed operand 解构工具
  dialect/
    lowering.rs          目标跳转回填、多指令合并与 LoweringMap 构造
    puc_lua/             Lua 5.2~5.5 共享 lowering
    lua51/               Lua 5.1 lowering
    luajit/              LuaJIT lowering（含模板表、split method、64 位字面量、类型守卫）
    luau/                Luau lowering（含 FASTCALL、复合指令、插值、按值捕获、共享闭包）
  debug.rs               low-IR 调试视图
```

## 向上游/下游承诺的稳定事实

| 事实 | 含义与下游消费方式 |
| --- | --- |
| **`LowInstr`** | 统一寄存器指令集：赋值/加载、一元/二元/拼接、表读写/建表/`SetList`、上值/全局访问、调用/方法/尾调用、`Return`、条件分支/无条件跳转、数值与泛型 `for` 协议、`Closure`、`Close`/`ToBeClosed`、Lua 5.5 `ErrNil` 等 |
| **`LoweringMap`** | 维护 `low <-> raw` 指令下标映射、PC 边界与行号提示，供 debug 定位与 Web CFG 对照 |
| **`constants`** | 与 Parser 共享 `Arc<[RawLiteralConst]>` 冻结常量池，避免复制大表/字符串载荷 |
| **`ValuePack` / `ResultPack`** | 显式标注调用参数、返回值、变参、`SetList` 的固定宽度或开放尾包（`OpenFrom(reg)`） |
| **`TableAllocation` / `TableTemplate`** | 保留建表容量提示及 LuaJIT/Luau 模板表数据，供 `Ast` 直接恢复表构造器 |
| **方法与 `FastCallProtocol`** | 将 `SELF` / `NAMECALL` / LuaJIT split-method 与 Luau `FASTCALL` 保留为显式协议，避免下游靠寄存器号猜方法调用 |
| **捕获与环境身份** | 显式标注 `Closure` 的捕获来源（栈槽或父 upvalue）、按引用/按值模式、可复用闭包身份，以及 Lua 5.2+ 的 `_ENV` upvalue 身份 |
| **`DebugLocals`** | 将各版本 debug local 坐标统一到指令索引区间，区分源码变量与编译器内部槽（如 `(for index)`） |

## 协议边界说明

- 零长度 debug 区间仅作为声明位置提示，不强迫下游伪造虚假活动范围或保留无意义空语句。
- 仅发布语言级可观察语义所需的指令协议、捕获身份与常量池元数据，不向中段透传物理栈帧死槽假设。
