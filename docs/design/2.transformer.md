# Transformer / Low-IR

Transformer 将真实方言的 raw 指令翻译为统一 LowInstr，并保存原操作的协议与来源。
它不切 CFG、不推断 SSA，也不恢复源码语法。

## 入口与输出

入口：[mod.rs](../../src/transformer/mod.rs) 的 `lower_chunk` / `lower_raw_chunk`。

```text
RawChunk -> dialect adapter + shared lowering state
         -> LoweredChunk { LowInstr, LoweringMap, constants, debug facts, children }
         -> Structure
```

进入 CFG 前不再有需要后层解码的 dialect-specific opcode。
无法表示或协议不一致时返回 TransformError，不忽略 helper 或猜默认 operand。

## 子处理层

| Owner | 消费 | 生产与后继 |
| --- | --- | --- |
| [dialect/](../../src/transformer/dialect/) | 各方言 RawProto | 统一指令与原方言语义事实 |
| [dialect/puc_lua.rs](../../src/transformer/dialect/puc_lua.rs)、[puc_lua/](../../src/transformer/dialect/puc_lua/) | PUC 共有编码语义 | family helper，供真实版本入口使用 |
| [dialect/lowering.rs](../../src/transformer/dialect/lowering.rs) | raw PC、目标及多指令协议 | pending 状态、目标回填与完整来源映射 |
| [operands.rs](../../src/transformer/operands.rs) | typed operand | 共享解构，不推断后续数据流 |
| [debug_locals.rs](../../src/transformer/debug_locals.rs) | raw debug 范围与方言坐标 | DebugLocals 与活动 scope 查询；供 Structure 建立可信绑定 |
| [common.rs](../../src/transformer/common.rs) | 各 lowerer 的语义结果 | LowInstr、稳定索引、多值与分配协议模型 |
| [debug.rs](../../src/transformer/debug.rs) | 冻结 low-IR 与 mapping | 调试视图，不新增业务事实 |

family 只共享确实相同的语义，不能按 opcode 同名推定同义。
版本入口负责调度，共享 opcode 映射只有一个 owner。

## 稳定合同

| 事实 | 生产位置 | 消费边界 |
| --- | --- | --- |
| LoweringMap | lowering 事务 | Structure/debug 查询 raw PC、low 指令与 origin，不重扫或假定 PC 单调 |
| constants | 共享 Parser 冻结池 | ConstRef 保持原序与原始载荷，不复制未消费的 raw 模型 |
| DebugLocals | debug_locals | 保存原坐标、半开作用域与活动索引；SSA 绑定接受属于 Structure |
| ValuePack / ResultPack | 指令 lowering | 固定/开放宽度、参数和返回包保持显式 |
| TableAllocation / TableTemplate | 建表协议 lowering | 容量、模板与批次语义交给 HIR，不提前展开成独立写入 |
| method / FastCallProtocol | 多指令协议 owner | 保留原 callee、receiver、direct/fallback 及参数来源 |
| capture / closure 创建模式 | closure lowering | 保留父级来源、ByValue/ByReference、Fresh/MayReuse 区别 |
| environment identity | 全局/上值 lowering | 有身份的词法环境 cell 与无身份隐式环境分开 |
| CloseKind | cleanup lowering | 独立 Close 与 Return/TailCall 的清理时点、配对身份分开 |
| 入口清槽与循环数值化事实 | 方言 VM 协议 lowering | Dataflow 描述真实写回，后层不从语法反推 |

来源与协议描述回答“原操作是什么”，不自动授权 HIR 删除、移动或合并操作。
例如分配容量相同不证明索引写与数组批次相同，结果槽相同不证明同一闭包 cell。

原始字符串 bytes、整数/浮点类型及方言常量身份保真。
debug local 使用与原指令一致的 PC 坐标；可信 SSA、scope 冲突和最终名字分别由后续 owner 决定。
Raw 中仅用于解码的字段不复制到 low-IR；下一层真正依赖的新事实应在其自然协议 owner 显式发布。

具体 opcode 对照、数值化分支、容量编码、scratch 槽距与协议拒绝条件以实现为准。

## 排错

| 现象 | 首查位置 |
| --- | --- |
| 操作数、宽度或指令语义错误 | 对应 dialect adapter 与 family helper |
| target、helper 归属或来源错位 | dialect/lowering |
| call、method、fastcall 顺序错误 | 对应协议 lowering |
| capture / environment 身份缺失 | closure 与全局/上值 lowering |
| debug 活动范围错误 | debug_locals，再追 Parser 原坐标 |
| low-IR 正确而后层错误 | Structure 的正式查询与消费者 |

查看 `transformer` stage dump，命令见 [调试手册](../debug.md)。
